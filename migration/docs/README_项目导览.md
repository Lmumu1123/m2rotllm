# C2R 项目导览：迁移到另一台主机后从哪里继续

更新：2026-09-29。本交接覆盖服务器上现有接触式—毫米波跨模态诊断工作。仓库保留原来的 `BearLLM/`、`anomaly_detection/`、`research_proposals/` 目录布局；历史日期目录是实验归档，不代表日期越新就一定优于旧模型。

**当前链路已完成训练、推理、基线和独立复核，但最新 R2 批次尚未通过“接触准确率 >98%、雷达 >95%”的跨条件验收。** 早期小样本中出现的 99%–100% 与最新跨转速结果采用不同数据和协议，必须分别理解。

## 当前实际研究链路

```text
接触 DAT → 严格完整 XYZ 包 → 中间 4000 点/轴
        → 按模型定义的预处理 → 冻结接触模型 → 128 维教师表示
                                               │
                                    同故障/转速会话内求均值
                                               │ 特征监督
雷达 BIN → 4RX 复数距离 ROI → 每 50 帧/2 秒提取 128 维频谱
        → 训练折的 StandardScaler → 雷达 encoder → 接触特征空间
                                                        │
                                           同一个冻结接触分类头
                                                        │
                                          十类概率合并为四类诊断
```

新批数据的对齐单位是“同故障、同转速的采集会话”，没有可靠的逐包采样时间，所以没有建立每一秒接触与每两秒雷达的精确同步对。本轮没有重新运行语言模型生成报告，也没有在新 R2 数据上重新训练 RotLLM/UniFault；这些能力与多教师实验保存在历史目录。

R2 雷达输入是由复数信号计算得到的 128 维频谱形状，不是 IQ 原值直接输入网络，也不是图片。雷达 encoder 输出的是接触分类头读取的 128 维特征。`StandardScaler` 的均值和标准差、接触目标均值、物理读取器等全部按训练折拟合。每个模型的真实预处理约定不能仅因 embedding 维度相同就互换。

## 最新结果应如何使用

| 结果 | 准确率 | 解释 |
|---|---:|---|
| 旧修改版 Bear 接触头直接测新批次 | 30.61%，105/343 包 | 旧适配没有直接泛化到新数据 |
| 冻结 Bear 特征，仅重训接触线性头，整转速留出 | 31.49%，108/343 包 | 只改头不足以解决新工况 |
| 接触频谱，同一 DAT 前段训练、后段测试 | 99.16%，118/119 包 | 共享采集会话，不能作为独立泛化成绩 |
| 接触频谱，整条新转速 DAT 留出 | 41.69%，143/343 包 | 跨转速/会话仍然困难 |
| 雷达随机森林，同条件留出第 4 次录制 | 97.22%，35/36 段 | 纯雷达分类基线；不是 Bear 接触模型输出 |
| 雷达随机森林，整转速留出 | 37.50%，54/144 段 | 新转速下明显下降 |
| 雷达随机森林，整距离留出 | 27.08%，39/144 段 | 距离泛化仍不足 |
| 雷达完整对齐 → 旧冻结 Bear 头，整转速留出 | 28.47%，3 种子均值 | 当前目标链路尚未泛化成功 |
| 雷达完整对齐 → 折内接触诊断新头 | 31.02%，3 种子均值 | 新头未通过原公开数据精度保持验收 |

接触按一秒包统计，雷达表中按整段录制平均窗口概率后统计；不能把它们解释为同一粒度。所有种子一起报告，种子数量不增加物理样本数量。本轮 171 个神经 checkpoint 和 855 条指标已经独立重算核对，见[复核说明](../../anomaly_detection/r2_validation_20260928/independent_check/README.md)。

看过主结果后做的阶次/包络开发实验也已保留：匹配前端的 XYZ+RBF 分类器，固定 Hz 坐标为 44.90%，阶次坐标为 75.22%。阶次路径仍未正确识别 49 个滚动体包，且没有接入 BearLLM 或蒸馏给雷达。早期点插值版本未通过合成检查，其 81.34% 属于无效开发结果，不能当作有效改进引用。

## 需要同时保留的模型版本

原 NAS 下的模型资产在迁移仓库中映射为 `external/bearllm-assets/` 和 `external/bearllm-runs/`。大体积 Qwen 权重使用 `migration/model_parts/qwen_model/` 分片保存，由 `scripts/restore_artifacts.py` 校验并重组；不是只有下载链接的占位记录。克隆完成后仍需按根目录说明执行资产恢复和完整性检查。超过单文件限制的评测 JSONL 使用压缩档恢复；以迁移清单中的逐文件哈希为准。

| 模型/接口 | 位置 | 状态 |
|---|---|---|
| Bear 复现 FCN 与原 classifier | 模型资产清单记录的 `released-code-seed42/pretrain/fcn` | 冻结骨干及第一线性层，是多个实验的共同依赖 |
| 旧 v1 共享头 | `anomaly_detection/retention_alignment_20260922/results/retained_head_v1/models/v0/all_known/retained_head.npz` | **最新 R2 主链所用头**；历史源十类下降 0.3502、四类下降 0.3339 个百分点；部分数据源不满足严格逐来源要求 |
| 更保守的共享头 | `anomaly_detection/retention_alignment_20260922/results/retained_head_conservative/models/v0/all_known/retained_head.npz` | 历史原测试十/四类分别 98.8598%/99.0472%，总体下降 0.0081 个百分点；总体和九个来源通过 0.5pp，个别细工况未通过 |
| R2 折内诊断头 | `anomaly_detection/r2_validation_20260928/contact/diagnostic_heads/holdout_*.npz` | 独立探索版本，`accepted_for_source_retention=False` |
| R2 雷达学生 | `anomaly_detection/r2_validation_20260928/experiments/*/models/` | 171 个保存模型，包括主方法、负对照、输入对照；并非全部可部署模型 |
| 历史 Bear/Rot/Uni 教师与转换 | `encoder_validation_20260923*`、`frozen_bear_to_unifault_20260924` | 旧 8 条开发录制上的受控实验，不能继承为新 R2 成绩 |

**旧 v1 与保守版是不同头，不能把保守版的 0.0081pp 回归结果写成 R2 主头的成绩。** 分类头、输入 scaler、标签映射、空间变换、训练划分和教师版本必须一起保存；只有一个 `.pt` 往往不足以恢复整条链路。

## 历史工作如何衔接

- 9 月 19 日：原始 R0 的 room/narrow 环境、距离和转速实验，以及 4kHz 接触输入兼容检查。环境数据主要为正常轴承的运转/停机，不能当作四类故障泛化证明。
- 9 月 21–22 日：四类解析、首轮全链路、真实 LLM 演示、公开源能力保持与统一分类头；早期外圈 ROI 错误和多轮开发查看都在审计报告中说明。
- 9 月 23–24 日：修正旧雷达距离门后，比较真接触特征、只学类别、人为类别向量、错类别目标；接入 RotLLM/UniFault，验证仅用接触数据学习模型间转换和冻结雷达复用；全部仍属旧少量开发录制。
- 9 月 27–29 日：144 雷达录制的新 R2 批次，跨转速/距离与 2g 截顶审计。当前下一阶段应从这些失败和受控改进继续，不回到旧小样本高分来宣称完成。

`研究计划/论文设计` 与 `实际结果` 已在各原报告中区分。SenSys 投稿路线仍是研究目标；本仓库不能视为已经满足最终论文或部署验收。
