# 归档保护与复现命令审计

原始日期目录保留当时实际运行的代码和结果。**新主机继续实验使用仓库根目录的 `scripts/c2r.py run` 创建新工作区**；历史 README 的裸命令主要用于理解当时流程，不应不加区分地在原归档目录再次执行。

## 已确认的覆盖行为

| 历史入口 | 行为 | 新实验建议 |
|---|---|---|
| `r2_validation_20260928/radar/extract_r2_features.py` | 默认输出为脚本所在目录，能写入同名特征与元数据 | 使用新工作区，或显式指定全新 `--output` |
| `r2_validation_20260928/baselines/run_baselines.py` | 在固定 `baselines/` 下写 CSV/协议，不拒绝旧结果 | 只在新工作区运行 |
| `r2_validation_20260928/summarize_results.py` | 重写汇总 CSV、PNG/PDF 和校验文件 | 要重画或重算，先在独立副本中执行 |
| `contact/evaluate_new_contact.py` | 已有 `contact_features.npz` 就拒绝继续 | 新工作区从 HDF5 重算，不删旧文件绕过保护 |
| `contact/diagnose_loso.py` | 已有 `diagnostic_heads/` 就拒绝继续 | 新工作区运行 |
| `experiments/run_alignment.py` | 已有相应 head/feature 输出目录就拒绝继续 | 新工作区，每组参数单独命名 |
| `contact/order_domain/run_order_diagnostics.py` | 已有协议记录就拒绝继续 | 独立开发目录；不删除失败历史来替换成绩 |

归档里既有“只读统计”、也有会生成校验结果的脚本。名字带 `verify` 不保证对整个目录完全无写入，应按各入口检查输出位置。

## 新入口的运行方式

以下命令由当前 `scripts/c2r.py` 参数接口核对；最终是否在迁移环境通过，以根目录的迁移验证记录为准。先激活项目环境，从仓库根目录执行，示例工作区路径必须尚不存在：

```bash
python scripts/c2r.py doctor
python scripts/c2r.py verify --output /path/to/new_checks/verification.json

# 只用已归档的派生特征重跑主对齐，所有新输出写到新工作区
python scripts/c2r.py run alignment \
  --workspace /path/to/c2r_runs/r2_alignment_001 \
  --head archived --feature complex_shape --device cpu \
  --seeds 17 42 73

# 从已有特征重跑接触诊断头、纯雷达基线、主对齐
python scripts/c2r.py run full \
  --workspace /path/to/c2r_runs/r2_main_chain_001 \
  --head archived --feature complex_shape --device cpu
```

若要从迁移后的 HDF5 重做前端，需要真实数据路径：

```bash
export C2R_DATA_ROOT=/path/to/c2r_data
python scripts/c2r.py run full --from-exports \
  --workspace /path/to/c2r_runs/r2_from_hdf5_001 \
  --head archived --feature complex_shape --device cuda:0
```

`C2R_DATA_ROOT` 下应有 `upload/` 和需要的 `wide_cache_local/`。最后一个例子在可用 GPU 上运行，CPU 机器把 device 改成 `cpu`。新工作区部分依赖是指向归档资产的软链接，不应手工通过这些链接改写原模型；它们用于读取，不代表操作系统已经设置了只读权限。

`run full` 的含义是“当前所选 head/feature 的主链复现”，**不是一条命令跑完全部历史实验或全部 171 个模型**。完整旧结果还包括诊断头、相位/几何输入、重复/距离诊断、阶次开发与独立复核。复跑某一对照应另建工作区，保存不同参数和输出，不能多次往同一归档目录增删模型后再汇总为一个实验。

## 防止迁移后改变实验含义

- 主划分仍是整转速留出；同一 `contact_id` 下的全部接触与雷达必须服从该折归属。不能改成随机切窗口后继续引用原来的“跨转速”名称。
- 输入已提取不等于已学习标准化。scaler、目标均值、新头和读取器只在训练折拟合，不复用其他折参数。
- `all_known` 模型用全部旧已知录制训练，适合演示或外部检查，不能用它的训练文件报留出成绩。
- 同 DAT 前后段、同条件 rep4、留距离、留转速、新物理会话是不同测试问题；多随机种子也不是多次新采集。
- 复现当前 R2 结果是计算复现，不产生新的物理盲测。已经看到该批结果后修改前端或超参数，仍应记为开发迭代。
- 新接触诊断头的 `accepted_for_source_retention=False` 不能在迁移时改成 True。若更新模型，需重新运行源回归并按最多下降 0.5 个百分点判定。
