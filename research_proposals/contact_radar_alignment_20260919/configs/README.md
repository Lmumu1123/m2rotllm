# 候选雷达配置

这些配置从用户提供的 AWR1843 + DCA1000 配置派生，供独立对照采集；没有自动下发硬件，也未宣称已验证本机固件接受。

- `R1_single_tx_2khz.cfg`：单 TX、4RX，保留旧快时间与 192 chirp/100 ms，2 kHz 帧内采样。
- `R2_single_tx_5khz.cfg`：idle 改为 120 μs，192 chirp/40 ms，5 kHz 帧内采样。
- `R3_single_tx_5khz_gap_trial.cfg`：帧周期 39 ms，检验固件能否接受更小帧间空闲。

三者先保留 RX gain=48 作为单因素对照；如 ADC 削顶，另创建 42/36 dB 副本，记录不同配置哈希，不覆盖原文件。RX gain 改的是 `profileCfg` 最后一个值。

R2/R3 保留原 ADC 时序，其起采 5 μs、采样约 74.64 μs、ramp 80 μs。若硬件/固件不接受该余量，应按主方案另测快时间配置。R3 对固件每帧处理/校准时间要求更严，报错或丢包则退回 R2，不强行缩短。

采集时必须保存 SDK/DFP/固件版本、CLI 回执、DCA 丢包信息与真实文件大小。改变配置后，解析器的慢时间率、帧周期、mask 及任何每秒字节预算必须同步更新。
