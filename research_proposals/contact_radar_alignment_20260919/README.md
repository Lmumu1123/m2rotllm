## 图片与复核

`figures/` 含六幅原创彩图，每幅提供 PNG、SVG、PDF；正文引用 PNG，矢量文件可用于后续排版。图中文字使用英文，中文解释位于正文图注。所有图均为设计示意或解析构造曲线，不含实际测量性能。

```bash
python -m pip install -r requirements-figures.txt
python scripts/check_design.py
python scripts/make_figures.py
```

[核算结果.json](核算结果.json) 来自已实际运行的脚本，检查采样算术、PHI-S 的旋转缩放性质、理想循环相干的代数性质。这不等于实现或验证了雷达解码、时间对齐或诊断算法。

## 归档范围

打包文件包含文档、图片、脚本、来源元数据、既有 BearLLM 协议审计快照，以及附原许可证的 RotLLM SFN 源码。完整上游仓库、Git 历史、数据集和模型权重不纳入压缩包。工作区内的 `references/RotLLM` 为另行下载的上游仓库；包内只保留正文直接引用的源码摘录。

没有更改已有 BearLLM 训练任务。原方案生成时尚未评估实际 IQ；同日上传完成后的环境实验已另行保存并在上方链接，不能将设计示意图当作实测结果。方案中的超参数、采集规模、时间安排和成功门槛均为建议，论文贡献需由后续故障与迁移实验确认。
