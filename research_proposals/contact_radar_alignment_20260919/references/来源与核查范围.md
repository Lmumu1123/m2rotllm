# 来源与核查范围

核查日期：2026-09-19。设计建议、超参数与研究门槛是本方案提出的实验起点，不是所引论文的已验证结果。

| 来源 | 访问与核查情况 | 使用范围 |
|---|---|---|
| [BearLLM](https://arxiv.org/html/2408.11281v2) | 原文 HTML 与官方本地代码已读 | 原方法、输入接口、教师复现；局部实现细节来自实际代码 |
| [BearLLM 官方代码](https://github.com/SIA-IDE/BearLLM) | 本地已有仓库，只读检查；既有协议审计单列 | 没有重新训练或证明当前训练完成 |
| [RotLLM](https://doi.org/10.1016/j.engappai.2025.112544) | 出版社可访问摘要/方法片段，官方仓库已下载并检查 SFN | 不能声称已逐项复现论文所有实验或完整 RAG |
| [RotLLM 官方代码](https://github.com/SIA-IDE/RotLLM) | 提交 2fda9859da3537acf9909b62010995d7366b17ae | 独立副本在 references/RotLLM；打包版不附上游模型权重 |
| [R2E-Net](https://doi.org/10.1145/3770693) | ACM 正文不可访问；出版社提交 Crossref 的原始摘要已取得 | 仅支持任务、单向潜空间迁移与时空雷达编码器概述；不支持具体环境处理/loss 复现 |
| [R2E-Net 出版社元数据](https://api.crossref.org/works/10.1145/3770693) | 原 JSON 已保存 | 避免将自动生成的二手解读当原文 |
| [PHI-S](https://arxiv.org/html/2410.01680v1) | 原文公式已核查 | 方差平衡、可逆性；其不等于去结构是本方案的数学分析 |
| [mmVib](https://tns.thss.tsinghua.edu.cn/sun/publications/mmVib_MobiCom2020.pdf) | 作者公开论文 | 多反射振动测量相关工作；未实现其算法 |
| [Romeo](https://research.polyu.edu.hk/en/publications/romeo-fault-detection-of-rotating-machinery-via-fine-grained-mmwa/) | 作者机构摘要/出版信息 | 精细角速度诊断近邻；具体复现需原文细节与适用几何 |
| [雷达 AF 知识迁移](https://www.nature.com/articles/s41467-025-59482-y) | 原研究原文可读；页面有后续更正链接 | 只借鉴共享知识迁移方向，未援用临床性能作为本项目证据 |
| [循环谱](https://www.sciencedirect.com/science/article/pii/S0888327017300134) | 出版社方法/摘要可读 | 已有统计工具；本文理想不变性公式独立展开并列假设 |
| [Soft-DTW](https://proceedings.mlr.press/v70/cuturi17a.html)、[GDTW](https://proceedings.mlr.press/v130/cohen21a.html)、[CRD](https://arxiv.org/abs/1910.10699) | 原论文/出版页核实 | baseline 依据；本次未运行复现 |
| [DomainBed](https://arxiv.org/abs/2007.01434) | 原文研究范围/结论核查 | 严格模型选择的依据 |
| [AWR1843](https://www.ti.com/lit/ds/symlink/awr1843.pdf) | 官方手册，包括三 TX 同时工作供电条件 | 硬件能力；不代表用户 cfg 已经实机验证 |
| [TI RAW Capture](https://www.ti.com/lit/an/swra581b/swra581b.pdf) | 官方应用笔记已读取 | DCA 数据格式、字节预算的依据；本机 lane/IQ 布局仍需日志与数据核实 |
| [TI SDK](https://e2e.ti.com/cfs-file/__key/communityserver-discussions-components-files/1023/5415.mmwave_5F00_sdk_5F00_user_5F00_guide.pdf) | 官方 SDK 参数表 | chirp、ADC、IF HPF 参数语义 |
| [SKF](https://evolution.skf.com/us/vibrations-help-find-faulty-components-3/) | 制造商技术资料 | 故障阶次与轴承几何关系 |

六幅彩图均由 `scripts/make_figures.py` 绘制。它们是原创架构/协议示意与解析构造曲线，无实际采集数据、模型比较结果或未完成的性能声称。`check_design.py` 只检查算术和理想代数性质，不是雷达解析、对齐或诊断方法的测试。
