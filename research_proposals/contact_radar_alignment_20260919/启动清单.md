# 下一轮采集与最小实验

设备已确认：AWR1843 + DCA1000；三轴加速度约 5 kHz、4096 点/包，只有主机接收时间戳。主台架可换故障轴承、不可换电机；两种传感器均测电机外壳。

## 先处理三个具体问题

1. **采样不是连续的 1920 Hz。** 当前 chirp 周期 0.5 ms、192 chirp/帧、100 ms/帧，包内慢时间率为 2000 Hz；每帧在 200 个网格位置中有 8 个缺失。每个 chirp 保留真实位置及 mask。
2. **TX mask=7 不是 TDM-MIMO。** 只有 chirp 0，配置请求同时开启三个 TX；核实供电/固件条件与 CLI 回执。新增一组单 TX、4RX 对照，先建立明确可靠的相位前端。不要把 bin reshape 为 12 路独立虚拟通道。[TI AWR1843 手册](https://www.ti.com/lit/ds/symlink/awr1843.pdf)
3. **离得近不一定信号更好。** IF 高通 code 0 对应 175/350 kHz；当前斜率下 0.5 m 的 beat 约 167 kHz。先扫距离，观察 IQ 幅度、饱和、相位噪声与故障证据；不能仅凭距离近来选择工作点。[TI SDK 参数说明](https://e2e.ti.com/cfs-file/__key/communityserver-discussions-components-files/1023/5415.mmwave_5F00_sdk_5F00_user_5F00_guide.pdf)

## 每次必须保存

- 未修改的雷达 cfg、SDK/DFP/固件/采集工具版本、每条配置回执。
- DCA1000 的原始 bin、缺包/重排日志、采集起止时刻、帧数与文件校验和。
- 加速度 xyz 原始值、单位、包序号/样本计数（若能获取）、接收起止时间戳、包大小、标称采样率。
- 轴承实体 ID、已知故障类型/复合组成、装配日期、转速/负载、环境、距离、视角、雷达 ROI、接触式安装点。
- 校准片段与诊断片段边界；停机校准和健康旋转参考分别保存。

## 第一批最小数据

先选健康、内圈、外圈、滚动体四种状态；同一转速、同一几何，每类至少 3 次独立重录，每次 60–120 秒。采用相同采集流程，随机化类别采集次序，避免某一故障绑定某一天/某个安装方式。

随后在第二环境重复；有多个独立轴承时优先更换实体，而不是只增加同一 run 的窗口。主教师暂不负责复合故障；复合故障先用于未知状态拒识，再另做多标签扩展。

## 第一轮只跑四组模型

| 顺序 | 实验 | 继续条件 |
|---|---|---|
| 1 | 电机处加速度：包络/阶次特征+SVM，原 BearLLM，短包适配教师 | 在独立 run 上确有故障信息；教师不能只在公共数据上好 |
| 2 | 雷达：简单相位/复数前端+同类特征；强监督小 CNN | 匹配转速/安装后依然有效，且无采样伪峰捷径 |
| 3 | 冻结教师：logit KD、feature+KD | 正确配对优于跨 run 打乱，输出能接固定分类头 |
| 4 | 加不确定对应、循环统计、可观测门控，逐项加入 | 实体/环境留出上收益稳定；缺口与深衰落时拒绝行为合理 |

暂不把 PHI-S、SFN、RAG 作为第一轮工作的阻塞项。

## 哪些结论现在不能写

- 正常静止/正常旋转分类成功，不代表故障诊断成功。
- 0.8192 秒补成 1 秒，不代表恢复了原 BearLLM 的时长/频率语义。
- 10 Hz 及其倍频的循环特征可能来自采样窗，必须排查。
- 另一系统的好/坏各一台，只能作为外部案例；设备身份与状态混杂。
- 任何表格的性能数字都必须来自实际冻结测试，本方案没有预填准确率。
