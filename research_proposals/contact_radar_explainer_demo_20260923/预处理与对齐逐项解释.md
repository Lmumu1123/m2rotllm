# 从传感器到模型：预处理、对齐与结果口径的逐项解释

2026-09-23。本文解释当前实际代码，不把后续计划中的 IQ 时序网络、时频图网络或精细时间对齐当作已经实现。

## 1. 先看清楚模型到底吃什么

```text
雷达原始 ADC/IQ bin
  → 距离 FFT：判断反射来自哪个距离
  → 选电机附近距离门，保留 3 个 bin × 4 RX
  → 得到随 chirp 变化的复 IQ
  → 归一化、每帧去均值
  → 每帧沿慢时间做 FFT：计算振动相关的频率分布
  → 多帧/多单元功率汇聚
  → 5–800 Hz 汇聚成 128 个频带，取 log 并减去谱均值
  → StandardScaler：128 个数仍然是 128 个数
  → 雷达 encoder：输出 128 维学习表示
  → 与接触式同一个诊断头 → 四类概率
```

**当前 encoder 输入是一维的 128 维谱特征向量，既不是原始 IQ，也不是时频图片。** 批量接口为 `[batch,128]`。128 个输入数对应固定频带；128 个输出数是网络学习的隐藏特征，已没有“一维对应一个 Hz”的含义。两边碰巧都为 128，不意味着它们可以直接互换。

接触式路径不同：`XYZ 原始加速度→每轴一秒 DCT/DCN→query/reference 配对→BearLLM FCN→128 维 hidden→同一个头`。

“IQ 是预处理起点”和“encoder 直接吃 IQ”不是一回事。当前已保存的 `iq_frames` 也不是原始 ADC：它已经完成了距离选择、单元幅值归一化和帧内去均值。外圈原始正确距离附近的 IQ 没保存下来，不能在这个数组上重新选到正确电机。

## 2. IQ、两个 FFT、ROI 分别是什么

IQ 指复数观测 `z=I+jQ`：I、Q 是同一雷达信号的两个正交分量，不是加速度 X/Y 轴。`sqrt(I²+Q²)` 是复信号幅度，`atan2(Q,I)` 是相角。在单一、稳定散射体等假设下，相位变化可与沿视线位移相关；多径/多散射体下，不能把任意 IQ 相角直接叫真实电机位移。

这里有两种方向不同的 FFT：

| 操作 | 在哪里做 | 得到什么 |
|---|---|---|
| 快时间/距离 FFT | 同一个 chirp 内的 256 个 ADC 点 | 不同距离的反射强度和复数值 |
| 慢时间频谱 | 固定距离单元，沿连续 chirp 的 IQ 变化 | 振动、转动等造成的周期变化频率 |

ROI 是 Region of Interest，即“感兴趣区域”，这里主要指电机的距离范围。可理解为先从雷达中选出“我们要看的电机所在位置”。选错 ROI，就可能在分析其他反射体；后面的网络即使输出很高概率，也不证明电机故障被正确感知。

当前候选单窗数据形状：`[20帧,192 chirp,12空间单元,2个IQ分量]`。12 个单元来自 3 个相邻距离 bin×4 RX，彼此相关，不是 12 次独立测量，也不是已经分离的 12 通道 TDM-MIMO。

## 3. 雷达预处理每一步的意义和实际限制

### 第一步：降低固定幅度和静态偏置的影响

每个单元用该两秒窗口的幅度中位数做尺度归一化，再减去每帧的复均值。这能减弱整体增益差异和固定复偏置，但不能自动消除动态多径、频率相关结构响应或已经削顶的波形。

### 第二步：一帧一帧计算频谱

原配置 chirp 间隔 0.5 ms，帧内采样率 2000 Hz；一帧 192 个 chirp，约 96 ms。帧周期 100 ms，因此有约 4 ms 缺口。

当前主分支对每个完整帧分别加 Hann 窗并 FFT，合并正负频率功率，随后在时间帧上平均、空间单元上取中位数。这样不要求相邻帧的绝对相位连贯，也不会把两帧之间的缺口直接拼成连续波形。

它付出的代价是丢掉大部分帧间时间顺序，频率分辨能力主要受 96 ms 限制，约为 10.42 Hz。两秒包含更多用于平均的帧，但并没有得到两秒连续相干 FFT 的分辨率。补零求得 0.5 Hz 网格只是更密的求值点。

### 第三步：把谱汇总为 128 个数

5–800 Hz 被预先分成 128 个不等宽频带。每个频带求平均功率，然后取 log10，再减去当前窗口全部频带 log 值的平均数。

这样保留“谱形状”，弱化整体谱同时升高/降低。例子：如果两个信号所有频带都只差统一增益，中心化后可能很接近；如果某个结构只压低 100–150 Hz，中心化并不能消除这种局部改变。

128 维是**频带汇聚这一步**得到的，不是 StandardScaler 降维得到的。没有在当前主流程中使用 PCA、PHI-S、二维时频图 CNN 或原始 IQ encoder。

## 4. StandardScaler 到底是什么

它是逐个特征做标准化的工具，名字不代表神经网络。对第 b 个频带：

```text
标准化后的数值 z_b = (当前频带数值 x_b − 训练集均值 μ_b) / 训练集标准差 σ_b
```

例如某频带的训练均值为 3、标准差为 2，当前值为 7，则变为 `(7−3)/2=2`。这个例子只是解释运算，不是本数据的实际取值。demo 可以查看真实某一频带的 x、μ、σ、z。

`fit` 指只根据训练录制估计 128 个均值和标准差；`transform` 指把这组固定参数用于新样本。当前训练还采用录制等权，以免窗口多的文件占更大权重。测试/部署时不重新拟合，不能用整个测试环境的均值偷偷适配。

它的作用是改善各维数值尺度和优化条件，不会让不同电机自动变成同一结构。前后的向量维度都为 128。[scikit-learn 官方定义](https://scikit-learn.org/stable/modules/generated/sklearn.preprocessing.StandardScaler.html)

要区分两个“减均值”：谱中心化是在**当前一个窗口的 128 个频带之间**减均值；StandardScaler 是对**训练集同一个频带在不同窗口之间**估计统计量，两者不是同一操作。

## 5. 为什么雷达两秒，接触式一秒

| 模态 | 当前窗口 | 原因 | 没有证明的事 |
|---|---|---|---|
| 接触式 | 4000 点＝1 s | 匹配 BearLLM 固定一秒 DCT 的物理频率索引 | 一秒一定有足够可辨认故障证据 |
| 雷达 | 20 帧＝名义 2 s | 沿用早期环境实验窗口，汇总更多帧以稳定谱统计 | 两秒最优、必须两秒、与一个接触窗精确对应 |

两秒雷达有 3840 个有效 chirp 位置，对应约 1.92 s 的帧内观测；中间有缺口，不能等同于连续 3840 点信号直接 FFT。接触一秒来自某个完整包，包间还可能有发送等待。

**当前袋级方法不要求两个模态窗口数相同或持续时间相同；代价是不能声称逐窗时间对齐，也不能把两种窗口成绩当严格等时长比较。** 未来至少做雷达 1 s/2 s/4 s 汇聚对照，并按相同支持时段比较。接触式多个包有间隙时只能做多块统计融合，不能拼成假连续四秒。

## 6. DCT、DC、DCN、BN、query 的词典

| 名称 | 中文含义 | 在这里具体做什么 |
|---|---|---|
| DCT | Discrete Cosine Transform，离散余弦变换 | 把一秒波形写成不同余弦基函数的系数，用于 BearLLM 输入；不是分类算法 |
| DC | 直流/零频分量 | 波形平均值对应的分量；可能来自偏置、重力等，来源需设备信息确认 |
| DCN | 本项目沿用的 DCT 系数归一化表示 | DCT 后补齐/截断系数并归一化能量；不是另一个故障分类网络 |
| BN | Batch Normalization，批归一化 | 神经网络内部层的统计归一化；训练会维护统计，eval 时使用保存统计，当前教师冻结 |
| LayerNorm | 层归一化 | 当前雷达 MLP 中的归一化层；与教师 BN、外部 StandardScaler 不同 |
| query | 待诊断样本 | “这段信号是什么故障？”中的这段信号；这里不是注意力机制 Q/K/V 的 Q |
| reference | 健康参考 | 与 query 一起输入的已知正常信号，理想应工况匹配 |
| query–reference pair | 待测—参考配对 | `[2,24000]`，两通道不是两根加速度轴 |
| encoder / hidden / embedding | 编码器/隐藏表示/嵌入 | 把输入变成学习特征；当前对齐位置为分类头前的 128 维 hidden |
| bag | 一份录制对应的一组窗口 | 当前跨模态训练的监督单位，不是某种文件扩展名 |

一秒 4000 点 DCT-II 的第 k 项约对应 `k/2 Hz`，所以第 200 项对应约 100 Hz。DCT 有正负号，与只保留强度的 FFT 功率谱不同，不能随意取绝对值再交给原权重。[SciPy DCT 定义](https://docs.scipy.org/doc/scipy/reference/generated/scipy.fft.dct.html)

BN 的统计属于模型状态。即使权重未更新，若推理时误用训练模式，也可能改变统计或输出，所以此前比较过 BN 导出状态；它不是再次采样或改变故障频率。[PyTorch BatchNorm](https://docs.pytorch.org/docs/stable/generated/torch.nn.BatchNorm1d.html)

## 7. 六种 DC 是什么

准确说是“六种 DC/参考带宽预处理组合”，不是六种 DCT 变换，也不是六种模型。

| 组合 | 待测 query | 健康 reference | 所排查的问题 |
|---|---|---|---|
| 1，主 v0 | 去均值 | 已发布全频带，保留发布 DC | 复核原本流程 |
| 2 | 去均值 | 只保留 2 kHz 以下 | 参考高频超出传感器支持是否造成残差 |
| 3 | 保留均值 | 已发布全频带 | 是否需要与官方 demo 的 DC 处理相同 |
| 4 | 保留均值 | 只保留 2 kHz 以下 | DC 与参考带宽联合检查 |
| 5 | 去均值 | DCT 第 0 项清零 | 两边是否应该一致去 DC |
| 6 | 去均值 | 去 DC 并仅保留 2 kHz 以下 | 同时统一 DC 与可测频带 |

参考修改后重新做能量归一化。每种组合都用三套冻结权重运行，共 18 组；复训 FCN 在八个文件上均为 25% Acc。概率和逐轴情况有变化，但未恢复可靠分类，所以不能把后面的改善都归因于一个去 DC 开关。

## 8. 到底是频域对齐，还是时域对齐

当前是**以频域表示为输入的、学习隐藏空间中的集合对齐**。有三层区别：

1. 加速度先转为带符号 DCT；雷达先转为 IQ 变化功率谱特征，原始表示并不相同。
2. 两个 encoder 把这些表示变为 128 维 hidden；隐藏维度不是频率坐标。
3. 训练约束同一录制两侧的 hidden 均值、概率和类别结构接近；没有逐频点或逐时刻强制相等。

你的担心是对的：不同测点的点加速度与雷达散射响应通常不应直接逐点 MSE。但“不能直接波形相减”不等于“不能在时间域学习可比特征”；以后若动态任务需要，可以在工况/包络轨迹或学习描述子上做时间匹配。

频域也不天然解决一切。结构传递函数的频率相关增益仍会改变谱形状；雷达多径也可能形成凹陷。当前的共享 hidden 只是训练目标，不是已经证明的结构不变物理量。

## 9. bag 为什么可以不按窗口一一对应

假设同一次稳态录制中，加速度保留 7 个有效一秒窗，雷达有 61 个两秒窗。虽然不知道哪个窗与哪个窗精确同时，仍知道这两组来自同一台设备、同一次故障状态。

```text
接触式 bag = {h_c,1, h_c,2, …, h_c,7}
雷达 bag   = {h_r,1, h_r,2, …, h_r,61}
对齐目标   = 两个集合在标准化 hidden 空间的均值接近
```

训练实际每步从每个雷达袋抽 16 窗，接触目标来自训练袋的完整有效窗口；另加概率蒸馏、同类对比，以及每个雷达窗的真实标签 CE。只有训练录制参与建立原型。

合理性的条件是：片段内状态/速度/负载稳定，两侧采样有代表性，统计量包含分类信息。这类似从同一个状态取得两组样本，比较它们的统计规律，而不是要求每次机械冲击都一一相等。缺测若偏向某个状态、录制内有变速或故障切换，这个前提就可能失效。

数学上，求和对排列不敏感，所以打乱袋内窗口顺序，均值损失不变；实际两模型各 50 次排列，损失变化仅约 8.33×10⁻¹⁶。**它可以作为稳态分类基线，但它不能证明事件级同步。** [Deep Sets](https://papers.nips.cc/paper_files/paper/2017/file/f22e4747da1aa27e363d86d40ff442fe-Paper.pdf) 提供集合建模依据，不保证当前均值一定足够。

目前每类训练只有一个袋，录制原型和类别原型几乎重合。因此还要加入“同类同工况但错误录制配对”实验，判断是否真正需要录制内的对应关系。直接说“精细跨模态对齐已经完成”是不准确的。

## 10. 49.8% 怎么变成了约 99%：事实上不是同一个实验恢复了

**没有完成“把原公开数据全部变成 4 kHz 输入，再恢复到约 99%”这个实验。** 前面的描述将不同结果放得太近，容易让人产生这个误解，需要明确纠正。

4000 Hz 是采样率，最高可测频率理论上低于 2000 Hz。早期实验并不是把真实硬件重新设为 4000 Hz 采集，而是把已有公开 DCT 的高频系数清零、重新归一化，模拟“只保留共同低频证据”的一部分影响；没有模拟实际抗混叠滤波、传感器噪声和传播路径。

| 数字 | 哪份数据 | 哪个模型/处理 | 指标与正确解释 |
|---|---|---|---|
| 94.9%→49.8% | 426 条公开测试 query | 冻结旧 FCN；原带宽→仅保留 2 kHz 以下 | macro-F1；原权重带限后明显退化 |
| 99.0553%→99.0472% | 12279 条公开 test query | 原完整发布输入；原头→保守适配头 | 合并四类 Acc；旧协议能力回归，不是限带恢复 |
| 25%→录制级 100% | 本地主台架八份录制 | 原头→适配头；实际 4 kHz 接触数据 | 录制平均后的结果；窗口错误被聚合掩盖 |
| **79.31%** | 本地 58 个接触式一秒窗 | 4 kHz 数据＋两个录制留出适配头 | 单窗 Acc；仍明显低于目标 |
| 99.76% | 本地 412 个雷达两秒窗 | 雷达 encoder＋对应共享头 | 雷达 Acc；含外圈错误 ROI，仍属探索性 |
| 91.38% | 同一批 58 个接触窗 | 全八份训练后的保守头 | **训练拟合**，不是新的留出成绩 |

因此，现阶段所谓“兼容”有两个层次：输入长度/频率坐标兼容已经实现；4 kHz 接触式的高精度、跨结构知识兼容尚未解决。原头在完整带宽旧数据保持约 99%，并不意味着对缺失高频的新设备也保持约 99%。公开旧协议还有重复和跨集合参考问题，不能当严格独立泛化。

## 11. ROI 幅度统计和环境表格怎么读

环境表格使用的是 room/narrow 那批**正常轴承**数据，识别的标签是转速或运行状态，不是正常/内圈/外圈/滚动体。

“ROI 原始幅度统计”基线具体是：在三个距离单元×四 RX 上，计算各单元平均复数幅度平方，并取 log，形成 12 个数。它问的是“反射有多强”，没有提取完整振动频谱。不同距离、朝向和环境散射会影响幅度，因此用于对照这种容易受环境影响的输入。

| 表格列名 | 训练 | 测试 | 预测类别 |
|---|---|---|---|
| 三转速 room→narrow | room | narrow | 1000、2000、3000 rpm |
| 三转速 narrow→room | narrow | room | 1000、2000、3000 rpm |
| 四状态 room→narrow | room | narrow | off、1000、2000、3000 rpm |
| 四状态 narrow→room | narrow | room | off、1000、2000、3000 rpm |

每一行是不同的前端特征，接同类逻辑回归分类器；表内数字是先汇总每份文件窗口概率后的文件级 macro-F1。超参数只在源环境选择，目标标签用于最后评价。

例如多单元 IQ 谱形状的三转速两方向 100%/93.3%，意思是转速分类跨这两个地方的表现；不是跨环境故障准确率。只找 10–60 Hz 主转频的基线两个方向都是 100%，说明这个任务很容易利用轴速线索完成。未见距离还有 50.0%/55.6% 的失败单元，不能说环境和距离影响都已消除。

主表训练域已经包含 20/40/80 cm；它本身也不是未见距离测试。真实目标仍是“同转速、不同故障、未见环境”的区分，需要新故障实验。
