# 目标澄清、冻结验证的作用与 cfg 小试

2026-09-24，依据用户本轮澄清更新。本文没有新增训练结果，也没有运行或下发雷达配置。

**研究目标是建立接触—雷达跨模态知识适配框架，让后续雷达观测能够使用接触数据训练的诊断模型。减少重采或模型升级成本至多是潜在附带收益，不再作为本项目主目标。** 跨接触模型转换是兼容性辅助实验，不承担核心创新证明。

## 1. 物理指标读取器检查什么

它检查“表示里是否保留了某项可以测量的信息，而且接触端学会的读取方式能否用于雷达表示”。它不直接检查两条原始波形是否相似，不要求加速度与复 IQ 有相同幅值、相位或单位。

以谐波能量比例为例：

1. 从接触原始信号按固定规则计算该比例，作为观测目标。
2. 用接触训练表示训练一个小读取器，预测该比例；冻结接触特征网络。
3. 在独立接触验证录制上先检查读取器有效性，与“类别＋转速”等简单答案比较。
4. 冻结读取器和已经训练好的雷达 encoder；雷达训练不使用这项新目标。
5. 用该读取器读取雷达表示，与对应稳定录制的接触观测统计量比较。

若通过，说明该信息可以从雷达表示中按接触端规则读出；不能据此宣称恢复完整原波形、掌握全部故障知识或证明损伤严重程度。未同步逐窗的旧数据只适合比较录制统计量，不能把它写成瞬时属性重建。

RMS、峭度是一般振动描述，也可能受安装、工况和噪声影响；具有诊断含义的包络／谐波指标仍须先确认可观测性。仅预测由类别和转速公式计算的理论故障频率，不能排除学生只记住类别。

读取器应小、规则预先固定，并完整报告所有候选目标。该方法论参考了受控 probing 的思想，但原语言模型实验不是本地振动诊断的直接证据。[Hewitt 与 Liang，2019](https://aclanthology.org/D19-1275/)

## 2. 冻结 backbone 不等于 backbone 没有作用

冻结参数只是停止更新；输入信号仍会经过不同的固定函数，得到不同信息。若骨干把某项信息完全删掉，后面的头无法从这些特征中凭空恢复。

不过，需要准确纠正当前实际结构：

```text
接触预计算：
接触原始信号 → 接触预处理 → 冻结接触 backbone → 教师特征缓存

雷达训练：
雷达输入 → 可训练雷达 encoder → 雷达特征 → 冻结接触分类头
                                      ↕
                            教师特征提供监督目标
```

**雷达 forward 没有经过接触 backbone。** 接触 backbone 的作用是定义学生应学的目标；最后分类头检验学生输出是否可用于诊断。接触头本地适配和雷达训练是先后两个阶段，不是雷达标签同时更新这两个部分。

如果只用类别 CE，学生只需落到分类头判断正确的区域，许多不同向量都可以做到。此时高分不能证明复制了接触特征。

加真实特征损失后，教师表示明确影响学生目标，但当前每折每类只有一个训练录制，录制均值恰好等于类原型。不同教师都能达到高分类分数，可能仍只是学到四个代表点。

因此现有三教师实验是有效的**接口适用性检查**，不是充分的**预训练故障知识贡献检查**。继续增加几个模型的四分类分数，不能补上这项证据。

### 更直接的补充验证

| 对照 | 要排除的解释 |
|---|---|
| 预训练教师 vs 同结构随机初始化、冻结的教师 | 任意高维信号投影是否已足够；教师预训练究竟增加了什么 |
| 真实录制特征 vs 每类教师原型 | 是否只需要四个类别代表 |
| 正确录制 vs 同类同速错录制 | 对应录制的具体信息是否有作用 |
| 相同雷达骨干＋自由分类头 | 不使用接触接口，雷达自身能做到多少 |
| 冻结接触新读取器读雷达 | 是否能获得四分类之外的实际功能 |

随机教师对照必须相同输入、维数、训练数据与本地头适配规则，同时报告接触教师自身成绩。随机教师本身接触任务很差时，学生差不能单独量化“预训练知识迁移了多少”。人为四类向量也不能替代随机 backbone：后者仍随每个输入信号变化。

### 若希望检验更多接触主干的复用

可以增加一个中间层注入对照：雷达适配器输出接触模型某个中间层所需的特征，后续接触卷积层和分类头均冻结。中间表示由相应接触层提供监督。

这会更直接检验后续接触计算能否处理雷达生成的特征，但不天然比晚层对齐好；需控制学生容量、输入信息和训练预算。不能只是为了让架构图看起来穿过更多 backbone 而增加复杂度。若较晚层已删掉新指标，而较早层保留，才有充分依据将主方法改到较早层或增加多层监督。

## 3. A→C 转换确实是一个预期的兼容性结果

按用户记号：a 是模型 A 的接触表示，b 是雷达学出的表示，c 是另一模型的接触表示。如果 b 已经接近 a，且 T(a) 已能近似 c，那么 T(b) 接近 c 在条件满足时确实是预期结果。

对线性 T，这只是普通的误差传播：

`转换后的总误差 ≤ 转换对误差的放大倍数×雷达相对a的误差 + a转c本身的误差`

所以转换实验用于检查接口、测量误差和确认可用范围，不是单独的算法创新。真实风险在于新工况下 b 是否仍接近 a、a 是否包含 c 所需信息，以及转换是否放大误差。

也不能把“分类头仍能答对”直接当作两个表示信息相同。模型拼接研究已经展示，按类别聚集的随机表示也可能成功拼接。[Smith 等，ICML 2025](https://proceedings.mlr.press/v267/smith25a.html)

## 4. 按用户目标重排论文主线

主线应为：

> 从毫米波的异构观测中学习接触诊断模型可读取的故障信息，并在新录制、新转速和新观测环境下，仅用雷达完成诊断。

部署框架可以写为：

`雷达原始数据 → 雷达前端／共享encoder → 目标接触模型的接口适配 → 冻结的接触诊断模块`

“统一”要逐层验收：

1. 统一的训练与接入流程是否支持已测教师。当前有证据。
2. 同一个冻结雷达 encoder 是否经轻量接口服务不同教师。当前 Bear→Rot／Uni 有小规模开发证据。
3. 对后续新采数据是否仍有效，以及是否保留类别之外的具体信息。当前需要新物理实验。

不要求人为设定所有模型的特征坐标相同；接触模型可以保留各自正确的预处理与特征维度。若希望进一步训练一个共享雷达主干、配多个教师接口，这是可研究的路线，但不能把当前分别重训的三套学生称为已完成的共享多教师训练。

真正需要解决的困难是：不同测点与物理量、多径、带宽差异、采样缺口、无精确逐窗对应，以及新工况下信息保持。均值监督可作为起点，但须证明它不是只保留类别代表。

稳定状态下可以按录制集合监督；转速／负载切换时先按状态分段。若真实同录制目标与类内错配没有差别，应先检查数据是否具有类内变化及目标是否被均值抹去，再决定条件内分布或关系匹配；单纯增加损失项不构成验证。

## 5. 先做 cfg 小试，再选正式配置

当前 R1/R2/R3 是候选，没有本机验收结果。计算比较如下：

| 配置 | TX | 帧内慢时间率 | 连续chirp数／时间 | 帧周期／名义缺口 | 单帧基本频率尺度 |
|---|---:|---:|---:|---:|---:|
| R0 | 7 | 2000 Hz | 192／96 ms | 100／4 ms | 10.42 Hz |
| R1 | 1 | 2000 Hz | 192／96 ms | 100／4 ms | 10.42 Hz |
| R2 | 1 | 5000 Hz | 192／38.4 ms | 40／1.6 ms | 26.04 Hz |
| R3 | 1 | 5000 Hz | 192／38.4 ms | 39／0.6 ms | 26.04 Hz |

这些是 cfg 名义量，不是实机测量。加 Hann 窗后主瓣更宽。提高采样率扩大名义可观测频率上限，但固定192点会缩短观测时间；频谱补零或平均多个帧不能补出更长的相干观测。5 kHz 不自动优于2 kHz，R3也不解决短帧分辨能力问题。

### 第一轮：先检查可靠采集

R0（本机确认支持时）、R1、R2各做off、normal 2000 rpm、独立重启normal 2000 rpm，共9条。room、40 cm、测点、快时间参数先保持一致。off约30秒；运行数据以至少10个完整接触包为准，不强行一分钟截断。R3仅在R2通过后追加。

按顺序检查：配置回执与实际时序、IQ布局、通道、DCA丢包、确认削顶、实际距离峰、噪声与微振动可观测性、重复性。文件大小可整除不证明无丢包；须保存DCA日志。[DCA1000手册](https://www.ti.com/lit/ug/spruij4a/spruij4a.pdf)

### 第二轮：检查要迁移的信息是否实际存在

保留两个质量合格候选，normal与预先固定的一种故障，各在1000／3000 rpm独立采两次：两个cfg×两个状态×两个转速×两次＝16条。以接触与雷达共同可观测频带中的谱形／谐波变化、重复性和动态信号相对off背景的变化为依据，不要求两种波形或绝对谱幅相同。

如果都不够，优先明确缺的是频率上限、连续观测长度还是信噪比，再设计下一候选。增加连续chirp数须核对本机SDK内存、LVDS与处理／校准时间，不直接下发一个未经验证的长帧配置。小试都属于开发数据，正式D/E/F不得参与选cfg。

### 近距离还需检查快时间接收通带

当前斜率约49.99 MHz/μs，按理想静止目标的FMCW距离关系估算，20／40／80 cm对应的拍频约66.7／133.4／266.8 kHz。AWR1843模拟IF有两级可配置一阶高通，最低拐点分别175和350 kHz；因此近距离回波可能受到衰减，不能只根据强距离峰认定微振动信噪比已足够。这是硬件模型推导的核查理由，不是已测得本机的衰减或故障原因。[TI AWR1843数据手册](https://www.ti.com/lit/ds/symlink/awr1843.pdf)

TX=7也不等于12路可分离TDM虚拟天线；三TX同时使用有供电／模式条件，R0须核对板卡和回执。初轮先固定快时间便于比较；若证据显示近距离通带限制，再单独设计快时间候选，并重新核验带宽、距离分辨率、ADC结束时间和实际采集格式。

选择通过后锁定cfg、增益与解析版本再采主矩阵。不能凭少数小试的分类准确率选择“最好配置”，也不能继续用写死2 kHz／100 ms的旧解析器处理新cfg。

## 6. 本轮工作范围

只读核对了当前Bear／Rot／Uni的训练代码、转换代码和TI资料，修正主目标与验证定位；未新增模型成绩、未改变原权重、未控制硬件。之前的冻结转换结果仍然有效，其作用归为辅助兼容性证据。
