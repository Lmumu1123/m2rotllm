# 没有严重度标签，怎样验证雷达迁移了什么知识

核验日期：2026-09-24。本文是文献核验与待执行协议，不把拟议实验写成已完成结果。以前已完成的实验见 [第二轮汇报](/home/huangyating/anomaly_detection/encoder_validation_20260923_v2/第二轮验证汇报_故障知识与多教师复用.md)。

**可以使用多转速、多距离、不同环境和其他故障，不需要先获得严重度数据。关键是每组数据回答的科学问题不同。** 建议优先做“多转速下的故障信号读取”，同时用跨距离／环境检验读取结果是否稳定。新故障可做异常拒识或新接触任务迁移，但两者不能混称。

## 1. 先给每种数据安排合适的用途

| 数据 | 最适合回答的问题 | 单独不能证明什么 |
|---|---|---|
| 同一故障的多个转速 | 同类数据变化时，是否保留真实冲击／调制信息，跨未见转速是否仍能读取 | 只预测转速不等于故障知识；理论故障频率可由类别＋转速计算 |
| 多距离 | 改变雷达观测条件后，相同机器状态是否仍能正确诊断及读出 | 不能仅凭跨距离分类，声称比四类标签包含更多信息 |
| room / narrow | 环境多径变化是否破坏诊断和表示复用 | 只有正常数据时，不能估计各故障在新环境的召回 |
| keep 底座故障 | 四类以外异常能否被拒识；有接触标签后能否建立新任务头 | 未知异常不等于自动说出“底座故障”；也不能当作保持架故障 |
| 真正的复合轴承故障 | 单一故障训练后能否分别检出复合故障中的成分 | 固定四类 softmax 不具备多标签接口，不能直接宣称识别复合故障 |
| 其他电机健康数据 | 对新系统健康数据的误报警是否可接受 | 只有健康不能估计新系统故障检测能力 |

如果现有多转速／距离环境数据只有 normal 和 off，仍可完成健康误报、环境变化、转动与静止等验证；要验证故障知识，需把已有内圈／外圈／滚动体轴承也放到相同条件下采集。无需制造新的严重度。

## 2. 优先级一：读取真实的故障调制特征，而非重复问“四类是什么”

### 2.1 目标要来自信号，不能由类别答案直接写出来

普通的“这个信号是否为内圈”和“内圈理论频率是多少”证据太弱。给定轴承结构和转速，理论 BPFI/BPFO 等位置就可计算。若把这个计算值当标签，四类标签加转速就足够了。

更有区分力的是观测到的特征，例如：

1. 所有候选故障阶次附近的包络能量／邻近背景能量。
2. 同一候选阶次的二、三次谐波相对一次谐波的比例。
3. 候选阶次两侧、相隔一个转频的边带与中央分量的相对能量。
4. 预先固定的包络阶次谱若干区间能量，或有限维的整段谱形。

“阶次”就是频率除以转频。例如转频从 20 Hz 变为 40 Hz，某个分量从 80 Hz 变为 160 Hz，两者都是四阶。阶次分析可减轻变速导致的频谱展宽；不添加转速计的阶次分析已有正式方法，但其有效性依赖信号中能否识别转频相关分量。[Zhao 等，Sensors 2013](https://www.mdpi.com/1424-8220/13/8/10856)、[Borghesani 等，MSSP 2013](https://doi.org/10.1016/j.ymssp.2012.09.014)

以上均为本项目拟采用的观测目标，不是文献已经验证本地雷达可恢复的结论。必须统一计算全部候选阶次，不能按测试真类别只选择看起来最强的那条谱线。故障峰发生滑移、宽化或不明显时，保留其真实不确定性。

### 2.2 具体流程

1. 按独立采集会话划分训练／验证／测试，先划分再切窗。若只有每类一个轴承，只声称对这些轴承的会话／工况泛化；不能称未见实体泛化。
2. 从接触原始信号计算上述观测量。滤波频带、阶次容差、参考轴、谐波数只用训练／接触验证数据确定。
3. 固定接触 encoder，训练一个小型接触读取器。先检查在独立接触测试录制上，它确实能读取目标。
4. 固定雷达 encoder，将同一个读取器用于雷达表示；此步骤不让雷达使用新增观测量标签。
5. 对固定工况录制比较录制级统计量；对升降速数据，必须按可验证的稳定转速区间或可靠粗对齐分段。不能用“均值蒸馏不需精确时间同步”推导“任意动态信号都可乱配”。
6. 最后把转速留出，例如用 1000/2000 r/min 开发，3000 r/min 测试；循环方向属于开发对照，真正最终验收最好使用新会话。

原雷达 2 kHz 帧内慢时间率、帧间缺口和接触 4 kHz 有效带宽不同。首先检查每个观测量在雷达侧是否可观测。接触高频共振的包络虽然低频，仍不意味着低采样雷达必能重建它；补零也不能补出被删掉的共振。教师自身读不出或雷达观测不到的目标应明确报告，不应归结为训练失败。

### 2.3 必需对照与指标

| 对照 | 排除的简单解释 |
|---|---|
| 真实类别→训练类均值 | 只是记住四个类别代表 |
| 真实类别＋转速→训练回归；另加简单总体能量版本 | 只是识别转速／振动整体强弱 |
| 人为四类向量 | 只找到分类头认可的四个输入 |
| 每类教师原型 | 接触教师类代表有用，但没有具体录制信息 |
| 同类同转速内错配教师录制 | 对应录制中的细节是否真正重要 |
| 教师硬伪标签、软概率蒸馏 | 真实高维特征是否超过教师答案与置信度 |
| 原生接触读取器 | 老师自己能否提供该信息 |
| 直接雷达观测量回归，明确使用该目标监督 | 评估信息在雷达输入中能否被当前模型学出，不是严格上界 |

前述类别＋转速基线可以使用测试真实类别，是为了让基线更强；它仅用于科学分析，不是实际部署路径。其回归参数只能用训练数据拟合，未见转速时不能从测试条件求均值。

每个目标分别报告 MAE／归一化 RMSE、各类各转速误差、按独立会话聚类的区间，以及相对于“类别＋转速＋总体能量”基线的误差下降。优先报告类内误差；跨类别整体相关很高，可能只是四类均值不同。

如果真实特征监督持续优于上述强基线，并且原生接触读取也可靠，可以写“迁移了类别和转速不能解释的故障相关调制信息”。仍不写“掌握所有故障知识”或“证明真实损伤程度”。

### 2.4 最少需要怎样补采

可先固定 40 cm、一个环境：四类 × 三转速 × 三次独立会话＝36 条双模态录制。每次重新启动／独立录制，并记录轴承身份、安装、测点、转速设定、实际稳定性、距离、环境与原始 cfg。36 条是能开展对照的小试规模，并不保证统计显著性。

如果现有每类一个实体，三次会话不能被说成三个轴承。故障诊断研究已经明确展示同一实体跨训练和测试会带来过高估计，故正式结论需按实际数据分组限制。[Vieira 等，MSSP 2026，作者全文](https://arxiv.org/html/2509.22267v2)、[官方代码](https://github.com/gama-ufsc/bearing-data-leakage)

## 3. 优先级二：让读出的故障信息跨距离、环境仍有效

这是最符合非接触传感系统特点的实验。需要同时满足“保持有用差异”和“忽略无关差异”，不能只把所有表示压成一样。

建议以 40 cm、room 开发模型，完整留出 80 cm／narrow 做测量；20 cm 需先检查近场、耦合、饱和等质量。每类覆盖相同条件，采集顺序交错。若距离与故障类一一绑定，网络可靠距离猜类别，实验失效。

验收分为两层：

- 分类层：各条件 macro-F1、最差条件准确率、相对参考条件下降；健康误报警与故障漏检分开。
- 信息层：上一节冻结接触读取器的误差是否稳定、是否仍优于类别＋工况基线。

必要对照是相同雷达输入／架构／预算的直接 CE、软概率蒸馏、类原型、真实特征监督；预处理也要比较有无多径抑制、幅度归一化。所有 scaler、滤波阈值、距离选择和拒识阈值只用训练／验证确定。

若同一电机状态在不同距离连续采集，要记录接触信号是否也改变。不同时间采集不自动具有完全相同机械状态；用“同类同转速接触统计接近”检验可比性。目标选择可使用训练标签，但测试 ROI 不应按类别调到最利于分类的位置。

成功只说明“观测条件改变时诊断／所测信息可保持”。只有结合类内新目标的成功，才能进一步说“保留了该信息且对观测条件稳健”。

## 4. 优先级三：其他故障的正确使用方式

### 4.1 keep：先做异常拒识

当前 keep 经用户确认是底座故障，教师原四类没有它。四类 softmax 总会给出四类之一，其最大概率高也不能直接证明正常。先检查原生接触模型能否把 keep 与已知类区分。

选取简单、可复现的异常分数：最大 logit、能量分数、相对于训练接触表示的正则化距离。不要只选单个效果好的分数。固定同一分数分别作用于接触、真实特征学生、CE 学生、人为向量学生。强闭集分类器自身就可能具有异常拒识能力，因此 CE 不能省略。[Vaze 等，ICLR 2022](https://arxiv.org/abs/2110.06207)、[作者代码](https://github.com/sgvaze/osr_closed_set_all_you_need)、[Energy OOD 官方实现](https://github.com/weitliu/energy_ood)

报告 AUROC、AUPRC、已知类固定 5% 误拒率下的未知检出率，以及已知类分类准确率。固定 5% 的阈值必须在独立已知验证录制上确定，不能在 keep 测试上调。

同时测试“新距离的已知故障”和“原距离的未知故障”：前者应继续接受，后者才应拒绝。否则仅学会检测环境变化也会产生高 OOD 分数。

只有一两个 keep 录制，只能做可行性结果，切片不能制造大量独立未知故障样本。成功是“未知异常检测”，不是“零样本识别底座故障名称”。

### 4.2 新任务头：更强，但先要有可用接触证据

如果有多个 keep 接触录制，可以只在接触侧建立已知四类／底座故障新头，然后冻结雷达 encoder 检查它能否使用新头。雷达蒸馏阶段不能出现 keep 录制。如果既允许训练雷达 keep 又改为五分类，只能说明框架能扩展到第五类，不能说明旧 encoder 保留未教过的新知识。

若真实复合轴承故障可采集，给接触模型增加“内圈存在／外圈存在／滚动体存在”的多标签头；接触端先验收复合检测，雷达侧再冻结迁移。不能将“内圈＋外圈”硬塞成四类之一。公开轴承数据上的多标签评估有可参考的明确协议，但其数据仍然是接触信号，不能替代本地雷达验证。[Vieira 等，作者全文](https://arxiv.org/html/2509.22267v2)

## 5. 不增加硬件的受控干预：补充证据，不替代真实数据

### 5.1 同类错录制：最有针对性的教师干预

当前每折每类只有一个训练袋，真实袋均值等于类别原型，因此无法检验对应录制的重要性。补到每类每转速至少两个训练录制后，将同类同转速的教师目标交换，并保持所有类别、转速、训练预算一致。

比较正确对应、同类错录制、类原型三组在独立会话上的新目标读出误差。如果只交换对应关系就破坏新任务，而分类仍高，说明蒸馏确实使用了类别之外的录制信息。但这类信息可能是负载、安装或噪声；只有所测目标有诊断含义时，才可称故障相关。

### 5.2 删除故障相关频带与删除等能量无关频带

用训练数据固定候选包络谐波频带，在测试时进行预先规定的窄带抑制；设置宽度、删除能量尽量相近的邻带／随机带对照。比较教师与学生新目标读出的变化方向和幅度，同时观察类别概率。

这只是检查模型是否依赖这些信号成分，不等同于真实物理因果。数字滤波会造成分布外输入，必须报告干预强度，并用真实多转速数据验证对应现象。不要将不同模态施加相同 FFT 掩码当作相同物理干预：加速度与雷达位移的传递链不同。

### 5.3 已有输入如果已删掉信息，先改前端

当前雷达输入主要是频谱形状统计，不是原始长波形。若多个真实信号经前端得到几乎相同输入，encoder 无法从中重新生成已删掉的冲击时序。

可增加保留帧内有效时序的支路、包络／调制谱支路或若干短片段分布统计。比较这些输入对新任务的作用，避免只增加 MSE 权重。更高的测试分类准确率不能替代输入信息是否保留的核验。

## 6. 标注成本的公平说法

这批数据同一故障状态同时产生 DAT 和 bin，录制级故障标签通常是共享的。给接触录制标注“内圈”后，不能声称雷达同一录制还需要额外花同等成本标一次。

应明确至少四种预算：

1. 同一批双模态配对、同一批人工标签：CE 与特征监督是同标注预算。
2. 只有配对录制关系、不使用人工故障标签：比较接触教师硬伪标签、软概率、特征均值；教师预训练与本地头标签均需计入。
3. 某项新属性只在接触端有标签：冻结雷达后迁移新读出，可表述为不使用该新属性的雷达监督。
4. 固定接触教师下，使用更少配对录制：比较按独立录制数量绘制的性能曲线；这是配对数据效率，不自动是人工标签节省。

软概率蒸馏是基础必要对照，不应只与真实标签 CE 比。知识蒸馏本来就研究利用教师输出训练学生；本项目需要证明高维特征在什么条件下比这些输出提供额外价值。[Hinton 等，2015](https://arxiv.org/abs/1503.02531)

## 7. 为什么这些实验比再加几个相似度指标更有用

同一四分类头读懂了两种表示，并不能推出两者信息相同；模型拼接甚至可能在按类别聚集的随机表示上成功。[Smith 等，ICML 2025](https://proceedings.mlr.press/v267/smith25a.html)

新读出也需要约束复杂度、固定验证规则和对照任务，避免是读取器自己重新学会任务。[Hewitt 与 Liang，EMNLP 2019](https://aclanthology.org/D19-1275/) 本文借用的是评估原则，不把该语言实验当作故障诊断的直接证据。

因此建议论文把结论分成三条，逐条验收：

- 框架适用性：不同接触教师、正确输入与输出接口下，相同训练方法可工作。
- 表示可复用性：固定雷达 encoder，通过明确受限的转换，可被另一接触模块读取。
- 具体知识迁移：预先指定的故障相关目标，在独立工况下优于类别、转速和总体能量基线。

前两条成功仍是有价值的系统成果。第三条若失败，应定位教师是否含该信息、雷达是否观测得到、前端是否保留、损失是否约束，而非更换词语把分类高分包装成证明。
