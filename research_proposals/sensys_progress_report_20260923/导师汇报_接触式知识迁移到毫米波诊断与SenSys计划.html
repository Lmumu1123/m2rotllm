接触式诊断知识迁移到毫米波：阶段进展与 SenSys 投稿计划

导师汇报稿｜2026 年 9 月 23 日｜实验截至 2026 年 9 月 22 日

建议汇报题目：面向部署变化的接触式—毫米波跨模态故障诊断：模型复用、可信对齐与能力保持。

本文汇总已保存的代码、模型、逐样本结果及最新审计，不新增训练结果。文中“已实现”“已实测”“待验证”分别表示代码存在、已有对应实验、仍需新证据。历史报告与本报告有口径差异时，以最新审计和明确的模型版本为准。

1. 汇报开场：研究问题、当前进展和最重要的缺口

1.1 想解决什么问题

已有接触式振动模型积累了大量诊断知识，但安装加速度计会增加布线、固定和维护成本。本项目希望在训练阶段利用同步采集的加速度与毫米波数据，将毫米波映射到接触式模型的诊断表示空间；部署时仅使用毫米波，复用已有诊断头及可选的语言解释接口。

具体场景是：轴承故障产生振动，经台架和连接结构传播到旁边电机；两个传感器都在电机侧观测，而不是都直接测故障轴承。挑战同时包括弱传播、点加速度与空间散射差异、不完整采样、环境多径和不同电机的结构响应。

拟研究的问题不是“两个 encoder 接起来能否分类”，而是：在这些测量与部署变化下，怎样有依据地迁移可观察的故障知识，并保持原接触式模型的能力。

2.4 统一计分口径

  • 窗口 Acc：每个固定诊断窗口是否正确；当前接触式 1 s、雷达 2 s，不能冒称等时长比较。
  • 录制 Acc / macro-F1：先平均同一录制的窗口概率，再分类。macro-F1 是各类 F1 的等权平均，不等于 Acc。
  • 独立单位：至少完整录制，进一步按轴承实体、电机系统、环境划分；同一录制的三轴、窗口、不同 seed 不是独立物理实验。
  • 旧能力下降：适配前后在相同旧协议上的 Acc 差，单位为百分点；阈值 ≤0.5 pp。
  • 部署有效性：几何有效、数据合格、允许校准条件明确，然后才讨论 >98% / >95% 的验收。

3. 当前实际运行的算法链路

图 1：训练阶段存在接触式监督和故障标签；部署阶段仅雷达输入。虚线部分是下一阶段研究，不是已完成模块。

3.1 接触式预处理：固定物理频率坐标的 DCN

解析器仅保留计数完整的 1…4096 包，从每包提取 raw_xyz[48:4048]。每轴独立处理，不把 XYZ 当作 query/reference 两个输入通道。

a = 一秒加速度 − 该轴一秒均值
c = DCT-II(a)，保留系数正负号
v = 在系数末尾补零至 24000 维
F = 0.01 × √24000 × v / ||v||₂

近零交流量、非有限值或不完整数据需标记。主 v0 分支采用去 DC 查询和既有外部参考；其他 DC/共同带宽契约作为独立对照，不能在不同实验间悄悄替换。

DCT 第 k 个系数对应 fₖ=k fₛ/(2N)=k/(2T)。固定 T=1 s 后，不同采样率的同一索引对应相同 Hz；补齐长度保证模型接口统一；RMS 归一化减弱统一增益影响。这些性质不等于速度、轴承尺寸和电机结构不变性。 4000 Hz 实测仅支持低于 2000 Hz 的频率，补零无法补回高频信息。BearLLM 原文

3.2 教师表示与健康参考

输入为 [query DCN, healthy-reference DCN]；两通道不是两个轴。当前主流程固定使用来自公开训练来源的九条健康参考，每个本地窗口有 3 轴×9 参考视图，汇聚为 128 维 hidden 与概率。参考没有取自本地留出正常录制，但也不是同电机、同工况的严格匹配参考。

query/reference → BearLLM FCN → linear1 → ReLU → h_c ∈ R¹²⁸

FCN 与 linear1 保持冻结、eval 模式，BatchNorm 统计不更新。128×47 特征图中的 47 个位置来自频率输入卷积，不是 47 个时间片，不能直接对它做时间轴 DTW。

3.3 十类到四类：精确概率合并

四类顺序固定为正常、内圈、外圈、滚动体；对应原十类索引为 {0}、{1,2,3}、{7,8,9}、{4,5,6}。

g_c = logsumexp(l_j, j∈G_c)
p₄(c) = Σ[j∈G_c] p₁₀(j)

对外输出四类，内部保留十类用于旧任务回归及语言投影。不能用十类 argmax 后简单映射替代概率合并，也不凭本地四类标签虚构严重程度监督。

3.4 接触式分类头适配与旧能力保持

原模型本地表现不足；早期独立四类线性头虽能拟合本地录制，却严重损失旧数据准确率。因此当前使用可合并的零初始化线性残差：

l₁₀(h) = W₀h+b₀ + ΔW((h−μ_s)/σ_s)+Δb
L_head = CE_local,4
       + λ_s [CE_source,10 + 2T² KL(p_old^T || p_new^T)]
       + 0.001 mean(Δ²)，T=2

μ_s、σ_s 来自旧训练回放特征，σ_s 下限 0.01；不是后文雷达对齐用的本地接触统计。训练结束后残差可精确合并为共享的 weight10,bias10。零初始化只保证训练起点与原模型一致，训练后仍需验收。

已执行：1174 个旧 train query 回放；每步抽 256 个旧配对特征和每个本地训练录制 16 窗；AdamW，lr=0.003。首轮比较 λ_s=0/1/10/100、200/400/800 步；保守轮增加逐来源验证约束。最终保守 v0 使用 λ_s=10、800 步。回放参考跨集合的问题已在审计中发现，后续必须修正，见第 5 节。

3.5 雷达前端：距离门、缺口处理与谱形状

从 DCA1000 2I/2Q 布局解码后，每 chirp 去快时间均值、Hann 窗、512 点 range FFT；保持格式/共轭选择与硬件及几何一致，而非按类别分数挑选解码。

环境数据使用已知距离 ±16 cm、起始三帧平均功率选峰，保留三个相邻 bin×4 RX。同步故障数据早期在 0.15–2 m 搜峰，造成外圈/keep 错误 ROI；后续处理代码并没有凭空恢复未保存的正确 IQ。这是当前主链的实际输入缺陷。

当前主诊断分支采用：

  1. 单元尺度归一化，完整帧内去复均值，压制静态偏置。
  2. 在 192 chirp 的完整帧内加窗估计功率，跨帧汇聚；不依赖跨帧绝对相位连续。
  3. 跨 RX/range 单元稳健汇聚；在固定 5–800 Hz 的 128 个频带求功率。
  4. 取 log10，再减去窗口内 128 频带的均值，弱化统一幅度缩放。
  5. 训练录制拟合 StandardScaler，得到 128 维雷达输入；两个模态的标准化器分开。

2 s 只用于多帧汇聚；单帧约 96 ms 决定真实分辨能力约 10.42 Hz。零填充到 0.5 Hz 求值网格不会获得 0.5 Hz 物理分辨率。该特征是复 IQ 变化的谱形状，不是经过绝对标定的面位移。

已实现的并行对照包括：单单元相位增量、多单元非中心化 log 功率、相位谱拼接、固定平滑；环境实验另有只对有效 chirp 拟合正弦/余弦的带 mask 估谱。后者处理了时间缺口，但仍需跨帧相干性前提。

3.6 雷达 encoder 与共享分类头

128 维谱特征
→ Linear(128,128) → LayerNorm → GELU → Dropout(0.1)
→ Linear(128,64) → GELU → Linear(64,128)
→ h_r = ReLU(μ_c + σ_c ⊙ E_r(x))
→ 与接触式完全相同的十类权重 W,b → 合并四类概率

μ_c、σ_c 仅由本折本地训练接触 hidden 拟合，与分类头回放的 μ_s、σ_s 不同。输出 ReLU 保持与教师 hidden 的非负接口一致。雷达训练时共享头固定，只更新雷达 encoder。雷达不会通过原接触式 FCN 的原始输入层；它复用的是隐藏空间之后的诊断链。

3.7 当前对齐是录制集合蒸馏

一对同步录制构成一个 bag，接触与雷达窗口数允许不同。令 z=(h−μ_c)/σ_c，集合中心为各窗口 z 的均值。

L_feat = mean_b ||mean_i z_r,b,i − mean_j z_c,b,j||²
L_CE   = 每个雷达窗口经共享头得到四类概率后的真实标签交叉熵
q_c,b  = mean_j group(softmax(l_c,b,j / T))
q_r,b  = mean_i group(softmax(l_r,b,i / T))
L_KD   = T² mean_b KL(q_c,b || q_r,b)，T=2
L_con  = 基于袋均值余弦相似度的同类正例对比，温度 τ=0.2
L_radar = L_CE + L_feat + 0.5 L_KD + 0.1 L_con

温度先作用于原十类 logits，再合并概率，不是先合并四类再任意改温度。每袋等权，每步每袋有放回抽 16 窗；当前 Stage B 使用 AdamW，400 步、lr=0.001、weight decay=0.01、梯度截断 5，留出 seed=17/42/73。早期独立四类头版本为 200 步，不能混为同一配置。

完整损失使用真实故障标签，不是完全无标签迁移。每类只有一个训练袋时，对比主要提供类别原型约束；均值对齐不能证明每个窗口或冲击事件已经对应。

3.8 语言输出与仅雷达部署

当前版本使用 h_r→共享头→原生 p10→原 linear3/LoRA→5×1536 信号 token→Qwen2.5-1.5B-Instruct＋既有 LoRA。没有在本轮微调语言模型。

早期四类独立头曾将每种故障概率均分到三个严重度槽位；当前保留十类的方案已使用原生 p10，不再依赖该均分桥。两版语言结果分别报告。概率—文本一致性检查只允许标记/回退，不能把规则后的文本当 LLM 原始正确率。

已用删除标签、state 和接触信息的输入核验仅雷达推理。错误 ROI 的输出应标为候选/不可发布诊断；分类器能给出概率不等于物理测量有效。

5. 最新审计：影响结论可信度的实际问题

5.1 接触窗口质量不足以解释全部误判

88 窗均有限且形状正确，无整窗精确重复或 XYZ 同时平直。58 个主窗口中仅两个误判触发固定端点复查，其他十个错误没有该标记；RMS、峰度等在同一录制内也未稳定区分对错。

bigNormal 全 12 窗都有显著固定端点堆积：任意轴命中观测端点约 ±1.998604 的时刻占比，中位数 19.075%、最大 23.35%。这是量程/转换失真的复查线索，单位和档位未确认，不能直接宣称 ±2 g 饱和。

460800 部分文件完整包产出率低，滚动体为 3 个完整包/41 个观察到的包起点；该比例不是硬件真实丢包率，也不能证明保留的三个完整窗内部缺样。数据质量问题与算法域差异需要分别诊断。

5.2 公开协议有明确不独立，不能称“完全无泄漏”

对全部 135516 条发布 DCN 输入哈希审计：600 组精确重复，148 组跨集合；31 个 test query、92 个 val query 与 train query 输入完全相同。

原训练参考输入包含 25789 次测试 query 引用，涉及 6690 个不同测试 query。当前回放 query 虽来自 train，3522 个配对中仍有 715 次 val 参考、340 次 test 参考。旧模型和适配模型均继承了参考协议的问题。

本地录制划分、scaler 拟合、训练原型未发现直接使用留出窗口的路径，窗口与导出 IQ 帧也未发现精确重复；但同类两次录制是同一轴承，且现有数据被反复用于研究设计，所以只能作开发与录制留出证据。

仅删 31 条公开重复 test 后，旧四类 99.0529%、保守新头 99.0447%，仍只下降约 0.0082 pp；这说明这批重复不能单独解释高分，并不表示协议已经干净。需按原始实体/完整录制重新划分、限定训练参考并重训基线，或使用确实未见的新数据。旧协议保留作历史回归。

袋均值在任意窗口排列下不变；两个保存模型各 50 次排列的损失最大差为 8.33×10⁻¹⁶。证明的是当前目标不识别段内时间顺序，不是证明真实故障诊断永远无需同步。

稳态、同工况、代表性采样下，稳定统计量可以支持集合分类；变速、启停、窗口级 teacher 监督和冲击定位则需要时间关系。相关集合建模依据与严格条件见 Deep Sets 和本项目 时序条件证明。

7. 下一版算法：重点补接触式泛化，而非只优化学生

本节全部是待实施方案，不能计入当前完成的实验。

7.1 先明确为什么单一特征归一化不可能保证跨结构

在局部线性近似下，可把相同故障激励 Q(f) 经不同路径的观测写成 A(f)=H_a(f)Q(f)+噪声、R(f)=H_r(f)Q(f)+干扰。实际雷达还叠加多个散射体，未必满足单一线性位移模型。只有同位置、同方向且物理量可比较时，才可以直接讨论加速度与位移的二阶导关系。

幅值归一化可以削弱常数增益，不能消掉任意频率相关 H(f)。如果某结构恰好压制判别频带，任何算法都不能仅靠归一化恢复未观测信息。速度与轴承几何也会改变故障频率/阶次。因此需要有物理限制的假设、多个结构的训练/验证、以及不能诊断时的拒识，而不是宣布一组统计特征天然不受结构影响。

C2：简单可解释特征 有效带内包络谱、频带比、谱熵、冲击性、轴间一致性 载频是否在可测带内；接触物理特征＋线性分类的强基线

先在开发工况检查配置回执、DCA 包完整性、ADC 端点、静止噪声、目标 ROI 和跨帧相干性。RX gain 48/42/36 dB 可独立扫描，不与 TX、采样率同时改变后归因于某一参数。R2 更高慢时间率可能拓展可测带宽，但固定 192 chirp 的帧更短，帧内频率分辨力反而约为 26.04 Hz；若要细故障边带，需增加连续观测长度或证明跨帧相干。提高采样率不自动提高频率分辨率。

表示候选保留两个分支：稳健谱形状与帧内 IQ/相位时序；再按信噪比、几何稳定性汇聚空间单元。谱形状归一化、空间汇聚、off 校准、时序分支分别消融，不能把组合收益都称为“去多径”。

7.4 时间对应：按任务需要增加复杂度

  1. 录制对应：确认采集对、实际运行区间、两侧有效支持和缺口。
  2. 工况片段对应：用稳定的转频轨迹、公共频带能量变化等匹配状态；稳态无事件时允许只做袋监督。
  3. 时钟偏移/漂移：拟合 t_c=β+(1+ε)t_r，接收时间只提供粗约束；不把机械相位差全部解释为时钟差。
  4. 软窗口配对：在粗映射附近计算匹配代价，使用带斜率/搜索带限制与缺口 mask 的单调对应；对多峰或高熵匹配降权。可比较 Soft-DTW，但不将其低代价当真实事件对齐证据。

建议注入 ±0.1/0.5/1/5 s、±100/500 ppm 做预先固定的软件压力测试；它们不是实测时钟误差。稳态周期信号的延迟可能只能确定到模周期，变速锚点是可辨识性辅助，不是所有场景必须执行的假设。

7.5 可观察知识迁移的候选目标

在可靠教师和有效 ROI 建立后，再比较全部 hidden 匹配与受支持的任务信息匹配。候选权重分为三类：采集质量 q、配对可信度 a、教师可靠性 c，分别标定，不能把 teacher 高置信自动视为信号质量高。

L_next = L_CE + λ_bag L_bag
       + λ_pair Σ[i,j] a_ij q_i q_j ||P z_r,i − P z_c,j||²
       + λ_KD L_KD + λ_consistency L_same_state

P 是只在训练域学习或定义的任务/共有表示投影，不是已知真实物理公共子空间。需保留 P=I、无权重、只类别原型、同类错误录制配对等对照，证明收益不是容量或选择样本造成。

若用分类头的行空间强调决策相关表示，要说明十类中心化线性头秩至多 9，仅匹配它不等于匹配全部 128 维知识；相反，全部 hidden 中也可能存在雷达不可观察或只编码结构的信息。应同时报告分类、表示误差、同类同工况检索和跨结构结果。

8. 后续实验矩阵：按证据缺口逐级补齐

8.1 P0：先修采集与 ROI，避免积累更多同类问题

正常与滚动体、固定速度/负载/测点，两波特率各三次、每次 120 s，共 12 次独立会话，约 24 分钟净运行；另留静止参考。逐次保存原字节、包计数、时间日志、实际 cfg、量程、安装与距离照片。

验收：完整包产出、包内计数、端点比例、噪声、目标门、帧缺口都可追溯；120 s 不是 120 个有效连续一秒窗。异常标记不按模型对错确定，不通过跨包拼接补样本数。当前数据不删除，复采另建版本。

8.2 P1：可信接触式教师和主台架重复性

先一个转速四类各五次独立启动/拆装或跨日期录制，再扩成 4 类×3 转速×5 次＝60 次会话，每次 120 s，并以有效完整包数验收。正常校准记录额外采集，不兼任测试查询。

开发阶段每工况可按 3 train/1 val/1 test 的预声明录制划分；主论文若强调未知转速或实体，应另建立整速度/整实体留出，不能把同一速度随机留出叫转速泛化。至少对两种故障检查不同严重度，但没有可靠严重度标注时仅作附加描述。

同台架条件下先比较接触原模型、保守头、物理特征线性模型和新分支。主门槛仍为一秒窗 Acc>98%，同时看 macro-F1、各类召回、正常误报和旧能力 ≤0.5 pp；不能以测试后选窗口长度或剔除错误样本达标。

8.3 P2：跨电机泛化是独立课题，需先验证 teacher

严格区分三种协议，分别建表：

协议 对未见电机允许使用什么 可以声称什么
G0：零目标校准 部署已知几何/额定信息，按规则使用固定源模型；不拟合目标统计 零样本跨电机泛化
G1：独立正常校准 预留正常校准 run，可建健康参考/噪声统计；测试 run 不参与 正常校准后的迁移；不是 G0
G2：少量标注适配 预定数量目标电机标注 run，与盲测分开 少样本适配；不是未见域零样本

分两步采集：

  • 资源有限的第一步：至少三个可用电机系统的健康状态，各三转速×三次独立会话。检查接触式正常误报、参考敏感性、轴方向、带宽、端点及表征稳定性，再检查雷达。它只能验证跨电机健康误报，不能证明四类故障识别。
  • 完整版本：若能在三个兼容系统上都配置四类状态，可做 3 系统×4 类×3 转速×3 会话＝108 对录制，实施 leave-one-motor-system-out；训练侧内部再留验证电机/会话，避免用目标标签选超参。三个系统只是可执行起点，不是普适泛化的充分样本。

目前“一台好电机、一台坏电机”的外部系统如果健康状态与电机身份绑定，无法分辨模型学的是电机身份还是故障。理想做法是在同一外部系统更换轴承或维修前后采集，并记录真实故障部位；只有笼统好/坏标签时只评价二分类或异常检测，不能硬计四类准确率。主台架故障在远端轴承，外部故障可能在电机内部，标签和传递路径也必须说明。

尽可能增加独立轴承实体和不同尺寸；实际可行性取决于机械兼容，不能为了填矩阵将不同工况当不同实体。传感器重新安装、不同电机壳体测点是有价值的传递路径干预，但仍不等价于更换电机。若只能使用现有系统，论文范围应收窄到跨环境/位置及有限外部案例。

8.4 P3：同步故障的环境与距离泛化

建议主实验 4 类×3 转速×2 环境×3 次＝72 对录制，每对 60–120 s 且保证足量完整接触包，先固定优质距离与角度。源 E1 每类/速度两次训练、一次验证，为 24/12 对；目标 E2 共 36 对在方法冻结后评价。各环境的每类均覆盖同一转速/负载/配置，避免类别—环境混杂。

room/narrow 已经用于开发前端，重新采样不使它们成为“从未见过的环境”。可称新故障录制的跨环境测试；如果声称未见环境，最好增加未参与开发的 E3。多源域泛化方法至少需要两个训练环境，再留一个目标环境；不能在单源环境上假装验证多源 DG。

距离实验可在一个固定转速、固定其他条件下补 4 类×2 环境×3 距离×3 次＝72 对；与主矩阵重复的条件可共用一次真实会话并记录，不能作为两次独立样本。角度、遮挡、移动干扰单独追加，避免初期全因子爆炸。

主零校准协议不使用目标 off 或正常特征拟合统计；off 校准实验使用独立 calibration 集，明确是部署校准。每类不能固定一个距离、增益、串口设置或采集顺序。

8.5 P4：证明知识迁移有增益，而非只证明学生能分类

固定同一训练/验证/测试录制，使用同一 radar encoder 容量和训练预算。按录制数做 1/2/4/8 个有标签 run/类的数据效率曲线，条件不足的档位不伪造。已有标签、配对接触数据和公开预训练数据的成本分别列出。

设置三个独立比较：

  1. 等标签预算：雷达 CE、共享头 CE、KD、embedding、完整方法使用相同故障标签。
  2. 少雷达标签但有配对接触数据：明确标签是否可由同一次故障采集直接继承；不能隐藏这部分成本并称无标签。
  3. 跨域测试：在相同独立电机/环境上比较增益，报告最差域和每类召回。若只在同台架已有数据高分，没有迁移必要性证据。

还需同类、同速度但不同录制配对的负对照。若正确配对和错配效果相同，只能支持类别统计迁移，不能声称实例动态对应不可替代。

10. 评价协议、验收线和数据管理

  1. 先按实体/录制划分，再切窗口。 同步两模态、全部轴、原始文件分段和相邻重叠窗跟随同一归属。去重包括实际模型输入，参考库单独建表。
  2. 目标信息使用声明。 已知距离/额定速度、off、正常校准、未标注目标数据和有标注适配分别记录；避免不同方法偷偷得到不同条件信息。
  3. 模型选择只看验证。 当前八份和 bigNormal 均已见，不再称盲测；另采封存数据并固定评估脚本。所有阈值、quality gate、窗口时长、聚合时长在测试前确定。
  4. 同预算比较。 录制数、标签数、接触配对数、公开预训练量、网络容量和优化预算列全；至少三 seed 仅反映训练波动。
  5. 主指标。 单窗 Acc、macro-F1、每类召回、正常误报、录制 Acc；同覆盖时间的融合结果另报。按独立录制/实体做聚类置信区间，域数少时不制造精确显著性。
  6. 过滤与拒识。 同时报 Coverage、保留样本 Acc、正确输出数/全部输入数和各类拒收率。不能靠删除误判达到 98%/95%。
  7. 保持原能力。 历史旧协议用于同协议回归；干净新协议需训练参考隔离及新基线。≤0.5 pp 至少全局和逐来源约束；小工况退化仍单列，不隐去。

验收状态建议：接触式 1 s >98%、雷达预声明窗口 >95%、旧回归下降 ≤0.5 pp 三条保留；但阈值达成必须同时具备有效物理输入和独立测试。不同域逐域报告，不让一个容易域掩盖失败域。仅八次全对不能证明长期达到这些阈值；置信下界与样本量需另外设计。

  • 原始数据与采集：找回错误 ROI 对应 bin；确认加速度量程/滤波、采集软件原字节保存；是否可增加固件采样 tick/全局计数，不增加同步设备。
  • 时间投入：优先真实物理实验、强 baseline 和独立测试；SFN、PHI-S、RAG、额外大模型改造以可证明收益为条件，不全部并行堆叠。
  • 阶段决策：若新数据上纯雷达监督已足够，论文需转向明确的部署/成本/可观测性问题；若多电机 teacher 都不稳定，应先收缩泛化承诺、解决测量和接触诊断基础。

附录 B. 汇报时容易被问到的五个问题

Q1：现在雷达 99.76%，为什么还说没有完成？ 因为只是八份开发录制中的窗口结果，外圈 ROI 错误、同类实体共享，简单监督也高分；它证明接口优化能运行，没有证明有效物理测量上的独立泛化。

Q2：是不是接触式特征已经对电机尺寸不敏感？ 不是。固定时长 DCN 只统一 Hz 坐标和输入长度，不能消掉速度、轴承几何和壳体传递。跨电机 teacher 还未通过，必须独立补实验。

Q3：学生高于教师是否违背蒸馏原理？ 不违背。教师窗口先被汇总成正确的袋目标，学生还有真值 CE；两侧窗口时长也不同，79.31% 不是其监督目标的上限。

Q4：用了 LLM，贡献是否主要在大模型？ 当前主要是感知、表示与共享诊断接口。LLM 语言链已实跑，但没有证据它纠正诊断或产生系统收益，不能用文本流畅替代故障评价。

Q5：能否不做时间对齐？ 稳态集合分类可以作为无精细配准基线；动态过程、单窗监督和事件检索需要对应证据。是否增加复杂时序模块由负对照与动态实验决定。
