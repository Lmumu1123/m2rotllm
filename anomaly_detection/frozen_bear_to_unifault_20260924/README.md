# 冻结 Bear 雷达 encoder，转换后接 UniFault：已完成实验

日期：2026-09-24。**已完成之前缺少的“同一批 Bear 雷达 encoder 不重训，经过仅接触数据拟合的转换，交给 UniFault 判断”实验。** 本轮只拟合了两个转换矩阵，重新加载并推理了已有的 36 个雷达模型，没有训练新的雷达网络或分类头。

## 实际流程

`雷达 IQ → 既有距离修正与128维前端 → 冻结 Bear 目标雷达 encoder → 新接触转换 → 冻结 UniFault 本地四分类头`

训练转换时，取同一接触训练窗口，分别运行已有 Bear 和 UniFault 特征路径得到一对 128 维表示。对两个空间分别用训练录制拟合 StandardScaler，再拟合固定 alpha=1 的 Ridge 回归；每条录制总权重相同。最终合并为 `Uni近似特征 = W × Bear特征 + b`，W 为128×128，b为128维。

UniFault 特征含负数，所以转换后**不加 ReLU、不截断负数**。原 Bear 雷达 encoder 内原有的 ReLU 则保持不变；转换能把它的非负 Bear 坐标变成正负 Uni 坐标。这与“重新训练一个有正负输出的 Uni 学生”不同。

拟合转换不使用雷达、不向回归器提供故障类别、不使用测试接触窗口。后面的 Uni 新四分类头此前使用过接触训练标签，本轮仅加载并冻结。它的特征归一化已折进分类权重，本轮没有再次重复标准化。

这里的“直接 Uni 接触”指 Uni 特征加**本地四分类头**，不是原始语义映射尚未明确的16类头。

## 可以得到什么结论

可以把此前“只证明框架能为 Uni 重训学生”推进到：**已为 Bear 学出的雷达表示，也能通过仅接触数据训练的转换复用到 Uni 的四分类读取路径，无需重新训练雷达。** 加上已有 Bear→Rot，冻结复用目前覆盖两个目标教师。

在同样冻结复用协议下，真实接触均值／完整方法的窗口成绩与特征接近程度优于只学类别或人为向量。这支持真实特征监督对已有表示复用有帮助。

但不能夸大：人为向量在 Uni 路径上也达到100%录制准确率；不是只有真实接触特征才能接入。完整法比真实均值仅多正确一次重复窗口判定，且特征误差反而略大，不能说完整法已明显更好。此实验仍是相同四类任务，转换可能只需要恢复类别相关坐标，还不能替代类内故障信息的验证。

另外，直接接触转换55/58、雷达高于99%并不矛盾：不同路径的输入、噪声和平均方式不同；雷达学生原本学的就是每类录制代表表示，教师接触窗口成绩不构成学生分类准确率上界。

与此前为 Uni 重训雷达的约99.84%相比，本次冻结复用约99.84%–99.92%，说明这一小数据开发任务中冻结复用没有显著的表观分类损失；没有统计证据证明完全等价或泛化到任意教师。

## 审计与限制

- 两折接触拟合分别只用32和26个训练窗口，来自各4条训练录制；测试为相反的4条录制。fit_rows逐行保存训练窗口身份及录制平衡权重。
- 每折一个转换，共两个；36个雷达checkpoint全部重载推理，与旧缓存的隐藏向量最大差异小于1e-6，所有网络参数和缓冲区逐项不变。
- 每个旧输入、特征、分类头、雷达checkpoint的SHA256在运行前后核对。旧文件未改；所有输出仅在本目录。
- 外圈使用v2已修正距离的雷达前端；旧checkpoint文本里历史“ROI错误”说明不代表当前输入仍错误。
- 数据仍为多轮查看过的开发数据，每类两个录制来自同一轴承，不能称新轴承、跨环境或新故障泛化。每折每类仍只有一个训练袋，真实袋均值与类别原型不能区分。
- 本轮未训练或替换 Uni 头，且未新做原开源任务的保持性验收。旧原模型路径不变，不代表新组合路径已通过0.5个百分点验收线。
