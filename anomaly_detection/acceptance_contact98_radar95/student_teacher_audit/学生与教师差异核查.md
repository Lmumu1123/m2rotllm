# 学生与教师差异核查

**是同一个修改后的BearLLM诊断头在判断两种模态；但目前对齐的是录制袋均值，不是逐窗口复制接触式预测。** 因而不能用接触式单窗口79.31%，直接作为雷达学生的成绩上限。

## 实际重算

v0、seed42、两个录制留出方向；没有新增训练或选择模型。

| 路径 | 窗口正确数 | 窗口准确率 | 录制袋正确数 |
|---|---:|---:|---:|
| 接触式→共享诊断头 | 46/58 | 79.31% | 8/8 |
| 雷达仅bag embedding MSE→同一头 | 408/412 | 99.03% | 8/8 |
| 雷达仅窗口CE→同一头 | 409/412 | 99.27% | 8/8 |
| 雷达完整损失→同一头 | 411/412 | 99.76% | 8/8 |

这些准确率来自诊断分类头，不是逐窗口Qwen自由文本生成准确率。

## “同一模型判断”的证据

独立重建雷达encoder并重算概率，6个学生检查点的共享头W/b与对应接触式模型逐bit相同。根任务另从88×3×9=2376组DCN输入重新运行原FCN，hidden与归档缓存最大差0，再用同一个 `SharedFourClassModel.classify_embedding` 复现46/58和411/412。

## 为什么学生可以更高

| 损失 | 实际监督单位 |
|---|---|
| CE | 每个雷达窗口都有训练录制的真实故障标签 |
| embedding MSE | 雷达袋平均hidden与接触式袋平均hidden对齐 |
| KD | 两模态袋平均概率对齐，温度2 |
| contrast | 雷达袋均值与同类接触式袋原型接近 |

完整目标是 `CE + MSE + 0.5 KD + 0.1 contrast`。每步每袋随机取16个雷达窗口；没有要求雷达窗口逐一模仿某个判错的接触式窗口。

关键复算：**真正用于训练的接触式KD袋目标，以及MSE袋原型通过共享头得到的判断，都是8/8正确。** 接触式79.31%是聚合之前的窗口表现，而蒸馏目标是聚合之后100%的袋目标。两者层级不同。仅embedding已经99.03%，也说明完整模型的高分不能全部归因于额外CE；但仅CE也99.27%，同样不能宣称蒸馏带来了显著收益。

## 还不能证明什么

接触式约1秒/窗、雷达约2秒/窗，没有逐时刻配对，窗口数量和时间覆盖也不同。目前只能称袋级/类别原型对齐，不能称精细时序对齐或故障机理已跨模态迁移。

外圈100个雷达窗口ROI无效；去掉它们后的有效子集为311/312=99.68%，仍不是独立重新训练的三类实验。外部正常电机两模态均0/2；这些分数不足以通过完整物理泛化验收。若接触式>98%要求针对单窗口，目前79.31%明确未达标，不能拿投票后的100%代替。
