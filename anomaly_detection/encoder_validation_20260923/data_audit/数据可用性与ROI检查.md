## 3. 外圈距离门为什么不能在现有 IQ 上修复

两条外圈 NPZ 实际只保存距离单元 **43、44、45**，对应约 **0.864、0.884、0.904 米**。四十多厘米对应的距离单元没有保存到这些 IQ 数组中。

旧元数据的峰值列表中虽然还能看到约 0.462 米峰，但它只有峰的位置，没有那个距离单元随时间变化的完整复数信号。因此，修改距离标签、平移索引、重新归一化或者重新提取现有 IQ 特征，都不能把 0.884 米处的信号变成 0.45 米处的信号。

本轮再次运行已有重处理脚本的 `--check-only`：12 个原始雷达 bin 全部未找到，返回码为 2；没有创建伪造的修复结果。四类采集对应的 12 个原始 DAT 也没有找到，不过已导出的完整接触窗口仍然可用。检查过本地旧实验 ZIP 的文件目录，没有发现这些原始采集文件。

原始 bin 恢复后，可以先核验归档 SHA256，再对所有类别统一采用 0.45±0.16 米物理候选范围，并使用同一无标签幅度规则选取距离单元。此流程已经存在，但本轮**没有执行原始信号重处理**。

## 4. 为什么目前不能真正完成“同类错配”实验

已有两个互补留出折，每个训练折每类只有一个录制袋。

| 想做的对照 | 当前状态 | 原因 |
|---|---|---|
| 真实录制均值 vs 类别均值 | 可以跑，但目标数学上相同 | 每类只有一个训练录制，它的均值就是该类别均值 |
| 换成同类别另一训练录制的接触特征 | 不能形成有效对照 | 训练折内没有第二个同类录制 |
| 把测试录制的接触特征拿来错配训练 | 不可用 | 会使用测试信息，改变原有留出协议 |
| 将一段录制分成更多“袋”再错配 | 可以研究段内波动，但不能证明跨录制 | 新袋没有增加独立采集样本 |
| 使用 all-known 的每类两袋 | 能做训练机制演示 | 已无独立测试袋，不能据此报告泛化提升 |

## 5. 新任务验证还缺什么

当前有四类部位标签、keep 的类别外故障说明、另一台正常电机说明；没有同类故障轻重、负载或明确转速的新任务标签。不能从接触振幅大小自动编造“轻／重”作为故障真值，也不能把原来四类合并成正常／异常，就声称学生获得了新的诊断知识。

入口将递归匹配原始文件名，检查 12 个 bin 是否齐全、是否重名、字节数是否与归档一致，以及两次文件状态之间是否稳定。原始采集本身包含不完整帧尾，因此不要求文件大小恰好整除帧大小；会记录完整帧数和帧尾字节。DAT 可选，重处理沿用归档接触窗口；DAT 若已传入，会一并检查。首次默认检查只做大小与稳定性判断，不能替代内容哈希；`--verify-sha256` 可以在检查阶段增加完整哈希。

文件就绪后执行实际重处理：


`--run` 调用已经核对过的旧重处理脚本，固定 0.45 米中心、统一候选范围约 0.29–0.61 米；旧脚本会在导出前强制核对全部原始 bin 的 SHA256。默认输出是新的 `/home/huangyating/anomaly_detection/encoder_validation_20260923/geometry_corrected_r0_045m`。如果输出目录已有内容，拒绝覆盖；需要另选新的 `--output`。本入口不训练模型，不修改原 cfg，不下发雷达配置。
