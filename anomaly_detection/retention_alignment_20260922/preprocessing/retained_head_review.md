# 源域保持分类头：独立代码与结果审查

审查日期：2026-09-22。只读检查 `scripts/train_retained_head.py` 与 `results/retained_head_v1`，未修改训练实现、模型、选择记录或结果。所述 0.5 个百分点是本轮采用的验收门槛；不是文献保证。

## 审查结论

未发现本地留出标签或源测试标签参与训练、scaler 拟合或候选排序。该实现是**冻结原 encoder 与 linear1，只训练 linear2 的零初始化残差**，源训练回放约束与原十类知识蒸馏均进入损失。四类输出通过十类概率精确求和实现，没有平均 classifier 权重，也没有把四类人工均分回三个严重度。

9 个选定模型的原测试集整体十类、四类准确率下降均在 0.5 个百分点以内，六个录制留出方向均为 4/4 文件正确。但“整体门槛通过”不能写成“所有原数据来源不下降”：三个 all_known 模型都存在个别来源下降超过 0.5 个百分点的情况。应保留原模型作为可回退基线，报告这些变化，不能把当前测试集再次用于挑另一个更好模型。

## 数据和实现检查

| 检查点 | 结果 |
|---|---|
| 原 encoder 与 linear1 | 只读取冻结导出的 128 维表示；此脚本不能更新其权重或 BN |
| 可训练部分 | `delta=Linear(128,10)`，权重/偏置初始为零 |
| 初始化行为 | `original_linear2(h)+delta((h-mean)/scale)` 在初始化时等于原头 |
| scaler | 只用所选源训练回放 query 的 3 个 reference 表示拟合 |
| 训练 loss | 本地四类 CE + λ × (源十类 CE + 2 × 温度2的十类 KD) + 残差 L2 |
| 本地训练采样 | 每个源录制随机抽 16 窗，录制权重相等；不抽留出录制或外部数据 |
| 源监督 | 只用 source split=train 的 1,174 个回放 query；保留每个 reference 的特征，不把 mean-hidden误当mean-prob |
| 原域验证 | 所有 24,558 个原验证 query，3 个原 reference 分别 softmax 后平均 |
| 候选选择 | λ>0 且源验证十/四类下降≤0.005，再依本地训练 F1/CE、源验证分数及预设规则排序 |
| 测试顺序 | 每个模型先写 `selection_before_test.json`，再做新源测试预测；不以测试结果重选 |
| 原测试 | 12,279 个原测试 query，原 reference 协议不变 |
| 本地外部 | keep / bigNormal 不进入训练、scaler或候选选择 |
| 十转四 | `logsumexp(logits[group])` 与概率求和等价；映射 `[0,1,1,1,3,3,3,2,2,2]` |
| 保存头 | 将残差标准化显式合并进有效 W、b，供接触和雷达共享 |

原缓存的健康 reference 池包含部分验证/测试 query，且允许健康 query 自身作为 reference。此次继承这个协议以保证回归可比，已经在代码/源协议中写明。这是既有基准回归，不能称为参考完全隔离或未见设备的泛化实验。原测试的全部 257 个 condition 也在训练中出现；必须与实体/工况独立留出明确区分。

训练结束候选只受源验证与本地训练约束，仍可能过拟合很少的本地录制。选在训练 F1=1 的候选并不能替代局部独立验证集；当前只有每类两录制，故不建议继续复杂化模型或把这组文件循环当未见测试。

## 全局保持与局部退化

源测试原基线：十类 acc=98.86799%，四类 acc=99.05530%；十类 macro-F1=0.91406、四类 macro-F1=0.98727。

| 输入变体 / all_known | 十类 acc 变化 | 四类 acc 变化 | 下降较大的来源 |
|---|---:|---:|---|
| v0 | −0.3502 pp | −0.3339 pp | DIRG −0.9804 pp（102 query）；JUST −0.7956 pp（4399）；HIT −0.6224 pp（964） |
| query_no_demean | −0.4642 pp | −0.4316 pp | JUST −1.1366 pp；HIT −0.5187 pp |
| query_no_demean_ref2k | −0.3339 pp | −0.3420 pp | JUST −0.8184 pp |

这里的来源变化列为十类 acc。六个录制留出模型的来源最大下降为 0.2956 pp；不能将这个结论移用于最终 all_known 模型。10 类 macro-F1 也应独立报告：例如 no_demean all_known 为 0.89880，低于原 0.91406，说明只看总体准确率会掩盖稀有类别变化。

若未来要求每个来源均下降≤0.5 pp，须事先把 per-source 验证门槛纳入选择，并使用新的固定评估或明确标为开发迭代；不能在已经看过测试后偷偷挑另一个当前候选，再宣称测试未参与选择。样本极少的来源还应同时给出错例数，避免把单个样本变化误读为稳定趋势。

## 对前轮独立四分类头的回归检查

前轮只用本地录制训练的独立四类头，在原源测试的四类准确率只有 16.54%、17.11%、16.89%（两个留出方向与 all_known）。其本地满分并不表示能够替换原域的分类能力。此次原域回放、原十类 KD 与共享头是针对该缺陷的实质修正。

验收表述应为：“冻结原编码器，对共享原分类头做保留约束适配；本次原测试整体退化在预设范围内，本地录制留出可分类，但个别来源和类别仍有下降，跨电机尚需独立验证。”不能表述为“完全不影响原模型能力”或“所有旧域均得到保持”。

## 后续保守版本复核

另只读检查 `scripts/refine_retention.py` 与 `results/retained_head_conservative`。该版本在 v1 暴露来源退化后，明确开展第二次开发迭代：增加验证集**每个原来源**的十/四类准确率下降≤0.5 pp 约束，并在本地训练 F1 相同后优先较好的源验证准确率，降低继续拟合本地 CE 的倾向。候选只有 λ∈{10,100}、step∈{400,800}；代码未用新测试分数排序。

| 保守 all_known 版本 | 源测试十类 acc | 源测试四类 acc | 相对原十类 / 四类下降 | 最差来源十类下降 |
|---|---:|---:|---:|---:|
| v0 | 98.85984% | 99.04715% | −0.00814 / −0.00814 pp | HIT −0.10373 pp |
| query_no_demean | 98.79469% | 98.99829% | −0.07330 / −0.05701 pp | JUST −0.15913 pp |

两版本原验证、原测试各来源及全局均通过本次 0.5 pp 门槛。v0 选 λ=10、800 步，no_demean 选 λ=10、400 步；记录保存后再计算测试回归。这个结果比 v1 的整体门槛更符合“原能力不应明显下降”的要求。

**边界仍需明说：**因为开发方向受到 v1 的测试来源审查启发，同一原测试在第二轮是重复回归评估，不能包装成全新的盲测。此外，来源内还能划分出许多速度、负载与轴承条件，每来源达标不意味着每个 condition、每个类别或每条样本输出不变；更细粒度的退化需要另表披露。两个 all_known 模型训练使用全部主台架 8 录制，它们本地得分是训练拟合分数；不能以保守 all_known 的分数替代此前按录制留出的准确率。

## 完整原训练集与细粒度回归的最终复核

已另核对 `results/full_old_train_regression/metrics.csv` 和 `verification.json`：该步骤对冻结后的保守头进行评估，没有再训练或选模；覆盖原完整 **85,955 个训练 query、257,865 个 query/reference 对**，保持原已发布 DCN 及参考协议。

| 模型 | 原完整训练集十类 acc | 原完整训练集四类 acc | 新增错例 |
|---|---:|---:|---|
| 原头 | 100% | 100% | 0 / 0 |
| 保守 v0 | 99.993020% | 99.994183% | 6 / 5 |
| 保守 no_demean | 100% | 100% | 0 / 0 |

原训练集整体和各来源的准确率保持均达本轮 0.5 pp 门槛。训练集成绩只能说明旧训练样本的能力回归，不能证明未见泛化。

独立重载检查了 11 个头，保存目标概率重载差为 0。共享四类模型实际对比 27 个原始 query/reference 对，同批次冻结 FCN 表示与原模型逐项一致；与不同 batch 缓存比较时隐藏特征最大绝对差约 0.00323、相对 L2 约 0.000105，概率最大差约 4.95e-6，已披露为浮点/batch 数值差异，不能宣称所有缓存位级完全一致。

`results/retention_verification/condition_regression.csv` 表明每工况仍有下降：v0 最差为 XJTU condition 1037，57 样本少判对 1 个，下降 1.7544 pp；no_demean 最差为 JUST condition 818，122 样本少判对 3 个，下降 2.4590 pp。no_demean 十类 label 3 的召回还下降 4.3478 pp（23 个严重内圈样本少判对 1 个）。这些均不能被全局或来源门槛掩盖。

v0 原测试十/四类准确率只净少 1 个正确样本，但实际十类有 40 个预测标签改变、四类有 39 个改变；两者均有 19 个旧对新错和 18 个旧错新对。故应写“准确率净下降约 0.00814 pp”，不能写“只影响 1 条预测”或“输出完全不变”。

最后，完整训练集表中每来源 macro-F1 使用固定全部十/四类标签，某些来源并不包含所有类别，缺失类别计为 0。例如 CWRU 的 acc=100% 但十类 F1=0.1、四类 F1=0.25，是分母包含未出现类别的计分定义，不能解读为 CWRU 分类失败。主报告比较各来源时应优先用已明确协议的 accuracy，或另注明 F1 的参与类别。
