# 何时可以不做精细时序对齐：条件、证明与当前算法核验

结论：**稳态、同工况、整段故障分类可以先用不依赖精确窗口对应的袋级方法；这不等于接触式—毫米波任务普遍不需要时序对齐。** 当前损失不具备辨认段内时序的能力，因此现有高分类分数不能证明精细时序对齐已经完成，也不能证明它对变速或瞬态任务没有价值。

本报告将数学推导、已有论文结论、本地代码实测分开。没有文献能够无条件证明本台架、当前采样缺口及未知机械传递函数下都无需时间配准。

## 1. 当前代码到底对齐了什么

同一次录制中的接触式窗口记为集合 C={c₁,…,cₘ}，雷达窗口为 R={r₁,…,rₙ}。对应编码向量为 h_c、h_r；用训练接触式统计标准化后为 z_c、z_r。当前 MSE 为

\[
L_{bag}=\frac1d\left\|\frac1n\sum_{j=1}^n z_r(r_j)-\frac1m\sum_{i=1}^m z_c(c_i)\right\|_2^2.
\]

其他项分别是：每个雷达窗口的真实类别 CE、袋平均概率 KD、袋均值之间的同类对比。没有出现“第 i 个接触式窗口与第 j 个雷达窗口是否同时发生”的对应矩阵，也没有以真实时间戳构造配对监督。[实际训练代码](/home/huangyating/anomaly_detection/retention_alignment_20260922/radar/train_shared_head.py:99)

### 命题 A：当前目标对段内窗口排列严格不变

对任意排列 π、σ，求和的交换律给出

\[
\frac1m\sum_i z_c(c_{\pi(i)})=\frac1m\sum_i z_c(c_i),\qquad
\frac1n\sum_j z_r(r_{\sigma(j)})=\frac1n\sum_j z_r(r_j).
\]

所以 MSE 不变。KD 先求窗口概率再求平均，仍不变；对比项只读袋均值，也不变。CE 对同一袋内每个窗口都使用同一个类别，再取平均，也不变。由此，**任意段内排列都得到同一个全袋损失，正确时间排列不是该优化问题的唯一可辨认解。**

这不是说一个窗口内部的 ADC 样点可以乱序。窗口内频谱仍依赖信号结构；这里排列的是已经完成编码的完整窗口。随机 minibatch/dropout 会造成优化路径的数值波动，但不会凭空引入丢失的跨窗口时间监督。

本次从两折保存模型提取实际向量，每折独立打乱接触式/雷达窗口 50 次，复算全袋 CE/MSE/KD/contrast。结果与原顺序在浮点精度内相同。[复算代码](/home/huangyating/anomaly_detection/contact_quality_alignment_audit_20260922/theory/check_time_identifiability.py) · [数值核验](/home/huangyating/anomaly_detection/contact_quality_alignment_audit_20260922/theory/verification.json)

### 一个直接反例

设两个二维非负特征序列为

\[
h_c(t)=(2+\sin 2\pi t,2+\cos2\pi t),\quad
h_r(t)=h_c(t-1/4),\quad t\in[0,1),
\]

采用周期延拓。两者均值都为 (2,2)，故袋均值 MSE=0；但同一时刻逐维平均 MSE=1，且错开四分之一周期。**均值完美相等仍不能证明事件对齐。**

## 2. 袋级方法何时有合理的统计依据

以下是充分条件的分析，并非声称当前数据已经满足：

1. 一段内真实类别 y 不变，转速、负载、安装等工况 u 固定或其分布相匹配。
2. 两模态采样的是相同 (y,u) 下的过程。采样缺失不会系统性偏向某个转速阶段或振动相位。
3. 编码后的条件过程具有稳定均值、有限二阶矩，且相关性衰减足以使平均值收敛；不能把高度相关窗口当作独立样本。
4. 编码器已使两模态的条件均值具有可比较语义。原始点加速度与面位移本来不会自动满足这一点。
5. 类别可以由这些统计量区分，任务不要求报告每次冲击发生的时刻或重建波形。

在这些条件下，随着有效观测增加，袋平均估计各自条件均值 μ_c(y,u)、μ_r(y,u)，无需逐个样本配对即可训练条件均值一致。以标量平稳特征为例：

\[
\operatorname{Var}(\bar z_n)=\frac1{n^2}\sum_{i=1}^n\sum_{j=1}^n\gamma(i-j)
=\frac1{n^2}\left[n\gamma(0)+2\sum_{k=1}^{n-1}(n-k)\gamma(k)\right].
\]

若绝对自协方差可求和，该方差随 n 增大趋于零；高度相关时收敛慢，实际有效样本量远小于窗口数。公式由方差双重求和直接得到；平稳与自协方差的定义可参见 [CMU 时间序列课程](https://stat.cmu.edu/~cshalizi/dst/20/lectures/08/lecture-08.html)。

对向量袋均值，有一般恒等式

\[
\mathbb E\|\bar z_r-\bar z_c\|^2
=\|\mu_r-\mu_c\|^2+\operatorname{tr}\operatorname{Var}(\bar z_r)
+\operatorname{tr}\operatorname{Var}(\bar z_c)-2\operatorname{tr}\operatorname{Cov}(\bar z_r,\bar z_c).
\]

同一物理事件的双模态通常有关联，不能随意把最后一项设零。上式说明均值学习与方差、采样过程有关，不提供有限小样本下任意异步观测都等价的保证。

### 命题 B：整段分类可以只依赖稳定统计量

设共享头每个类别的 logit 对特征是 L-Lipschitz，接触式条件均值 μ_c 的正确类别与其他类别有正 margin γ。若某个雷达袋均值满足

\[
\|\bar z_r-\mu_c\|<\frac\gamma{2L},
\]

则正确 logit 相对任意其他 logit 的差至少为 γ−2L‖z̄_r−μ_c‖>0，预测不变。这个充分条件不包含逐时刻配对。

因此，“无精细配准仍能整段分类”在数学上可以成立；前提是统计量稳定、均值偏差小且类别 margin 足够。**该结论不保证单窗口准确率，也不保证跨电机时 μ_r 仍靠近 μ_c。** 本地另一电机、接触式低窗口准确率和采集不完整性均要求单独验证这些前提。

### 有限时间错位的边界

对有界特征过程 ‖z(t)‖≤M、完整均匀采样对应的连续平均，定义 z̄_T(a)=T⁻¹∫ₐ^{a+T}z(t)dt。两个窗口平移 δ、|δ|≤T 时，公共区间抵消，故

\[
\|\bar z_T(a+\delta)-\bar z_T(a)\|\le\frac{2M|\delta|}{T}.
\]

这只是边界积分的确定性上界：T 大于错位且过程稳定时，均值可能不敏感。缺口、选择性丢包、变速和不等时段覆盖会破坏它直接适用于当前采样的条件；不能用此公式宣称串口接收时间足够准确。

## 3. 文献究竟支持哪些结论

| 文献 | 可以支持 | 不能据此推出 |
|---|---|---|
| [Zaheer 等，Deep Sets，NeurIPS 2017](https://papers.nips.cc/paper_files/paper/2017/file/f22e4747da1aa27e363d86d40ff442fe-Paper.pdf) | 集合函数的排列不变结构；论文 Theorem 2 对可数宇宙给出 ρ(Σφ(x)) 表示，实数域另有条件讨论 | 一个现成 128 维均值足以保留所有故障信息；跨传感器无需对齐 |
| [Ilse 等，Attention-based Deep Multiple Instance Learning，ICML 2018](https://proceedings.mlr.press/v80/ilse18a.html) | 袋标签监督与排列不变的实例聚合，可用注意力汇总多个观测 | 每个实例都包含可辨认故障证据；注意力权重就是客观信号质量 |
| [Gretton 等，A Kernel Two-Sample Test，JMLR 2012](https://www.jmlr.org/papers/v13/gretton12a.html) | 在特征核等相应条件下，用总体 MMD 区分分布 | 普通有限维均值相等就是分布相等；分布相等就是事件一一对应 |
| [Oppenheim，MIT Fourier Transform Properties](https://ocw.mit.edu/courses/res-6-007-signals-and-systems-spring-2011/resources/lecture-9-fourier-transform-properties/) | 理想时间平移引入单位模的线性相位，傅里叶幅度不变 | 有限窗裁切、采样缺口、时间伸缩、带符号 DCT 或未知结构滤波都不影响表示 |
| [Cuturi、Blondel，Soft-DTW，ICML 2017](https://proceedings.mlr.press/v70/cuturi17a.html) | 可以构造对时间伸缩/偏移更鲁棒的可微序列对齐损失 | 算法得到的低代价路径就是真实物理事件对应；能自动消除位移—加速度与测点传递差异 |

这些论文提供建模依据，**不存在“引用 Deep Sets 即证明本任务永远不需要时序对齐”的推论。**

当前均值 MSE 相当于表示空间的线性核均值匹配。简单反例 P={0,2}、Q={1,1} 均值相同、方差不同。即使用更强的特征核匹配完整边缘分布，也不能恢复联合配对：同一序列任意排列仍具有同一经验分布。

傅里叶时间平移性质为

\[
x(t-\tau)\ \longleftrightarrow\ e^{-j2\pi f\tau}X(f),\qquad |X_\tau(f)|=|X(f)|.
\]

它解释了某些稳态谱形特征对绝对相位不敏感，但只适用于相应变换和边界条件。BearLLM 用带符号 DCT，不能直接套用“FFT 幅度不变”断言其输入时移不变。机械传递还会产生 Y(f)=H(f)X(f)，|H(f)| 并不因时间对齐而消失。

## 4. 对本项目的具体选择

| 任务 | 是否需要精细时序 |
|---|---|
| 同一稳态段的已知四类故障分类 | 可先不做毫秒级配准，但需要同录制、同工况、有效且有代表性的观测；保留袋方法为基线 |
| 速度变化、启停或负载变化期间的短时诊断 | 至少需要状态/时间段对应，避免将不同运行状态当正例 |
| 一个接触窗口监督一个雷达窗口 | 需要可验证的窗口匹配或置信度加权软配对，不能按索引硬配 |
| 冲击定位、瞬态事件检索、位移/加速度重建 | 需要更细时间关系，并且单独建模方向、导数和结构传递差异 |
| 证明模型学到了跨模态动态过程 | 需要同类同工况内的时间辨别测试；分类准确率或袋 MSE 本身不足 |

区分三个层级：①录制身份配对；②相同速度/负载的片段配对；③冲击/相位级精细配准。当前已利用①；②的工况元数据仍需补齐；③尚未得到实测真值验证。不能因暂未实现③就宣称它没有必要，也不应为了增加模块强行把不同物理量做无约束 DTW。

## 5. 最小验证实验：用证据决定是否增加时序模块

先修复测量问题、建立可靠接触式 teacher，并固定独立录制留出。然后安排两种状态：同速度稳定运行；使用已有电机控制器产生可重复的速度变化/启停段。设备安全允许的操作由实验者实施，软件不自动下发控制命令。

| 方法 | 训练约束 | 需要比较的指标 |
|---|---|---|
| M0 | 当前整录制袋均值 | 固定窗口/录制分类、真实标签 CE 对照、对齐误差 |
| M1 | 同速度/同负载片段的袋统计 | 同工况后是否减少不合理正例；元数据或轨迹估计置信度 |
| M2 | 时钟偏移＋线性漂移后，同时间区间配对 | 可控注入偏移/漂移的恢复误差、有效匹配覆盖率 |
| M3 | M2 后加入带斜率限制与缺口掩码的单调软配准 | 同类同工况内的事件检索/轨迹对应；不能仅比较故障分类 |

可预定注入偏移 ±0.1/0.5/1/5 s、漂移 ±100/500 ppm 作为软件压力测试；这些是设计的扰动，不代表实测时钟误差。原数据没有精确真值时，只能验证“已知注入变化能否恢复”，不能声称真实绝对误差已被测出。

负对照至少包括段内顺序打乱、同类同速度但不同录制错配、不同速度错配。M0 对段内顺序打乱不敏感是设计决定；若 M3 也无法区分动态段的正确/错配时间关系，其“时序对齐有效”的主张不成立。稳态周期信号还可能只能将延迟确定到模周期，需不同状态的可辨轨迹才有唯一时间线索。

变速锚点是一种提高时间参数可辨识性的采集设计，不是所有电机必须执行的通用假设。不同测点的频率相关相位不能都归结为一个时钟偏移；时间配准与结构传递建模应分别检验。
