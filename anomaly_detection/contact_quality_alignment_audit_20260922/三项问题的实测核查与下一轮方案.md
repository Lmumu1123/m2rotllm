# 接触式误判、数据泄漏与时序对齐：三项问题的实测核查

2026-09-22；全部计算在 `conda m2vllm` 完成。本轮没有重训、删除窗口、调整模型选择或覆盖旧结果。用户的接触式 >98%、雷达 >95%、原准确率下降 ≤0.5 个百分点约束继续保留。

**结论：一秒窗口误判不能直接解释为“这一秒没有故障”；采集质量确有部分问题，但无法解释全部错误。原公开数据协议确有跨集合参考及精确重复，不能称严格无泄漏。当前袋级模型可在一定稳态条件下不做精细配准，却不能证明精细时序关系已经学习或永远不需要。**

## 1. 一秒内为什么可能判错：重复冲击不等于可辨认信息充足

你的物理直觉基本正确：在持续旋转、承载且局部缺陷持续受激的条件下，轴承缺陷通常会反复激发振动。以理想无滑移、内圈旋转外圈固定的外圈频率为例，

\[
f_{BPFO}=\frac{N_b}{2} f_r\left(1-\frac{d}{D}\cos\theta\right).
\]

其中 N_b 是滚动体数，f_r 是轴转频，d/D 是滚动体直径与节圆直径之比。**仅作算例**：若转速 2000 rpm、N_b=8、d/D=0.3、接触角零，外圈冲击约 93.3 次/秒。当前这批四类数据的完整轴承几何与已确认轴速还不齐，不能把这个算例当作实测故障频率。[MathWorks 包络分析文档中的物理模型](https://www.mathworks.com/help/signal/ref/envspectrum.html)

因此，不能把目前十二个误判自动解释为“刚好这一秒没有冲击”。更需要区分：

| 可能原因 | 与“故障发生次数”的区别 | 当前证据 |
|---|---|---|
| 传递到电机壳体的振动弱或被谐波覆盖 | 缺陷冲击存在，但测点上可辨认分量弱 | 用户测点在旁接电机，具备这种可能；尚无逐窗因果验证 |
| 冲击激发的高频谐振超出传感器带宽 | 故障重复频率可能只有百 Hz，但承载调制的谐振在数 kHz | 4 kHz 采样支持低于 2 kHz；补零无法补回未采到的载频 |
| 切窗相位、轴向及参考组合改变了模型输入 | 冲击重复频率不变，带符号 DCT 系数仍可能随窗口起点变化 | DCT 不具有一般的时移不变性；是否导致本模型误判仍需连续原数据移窗对照 |
| 参考正常数据不匹配、模型决策边界或预训练分布不适用 | 信息可能存在，但模型没有正确利用 | 当前外部参考并非同机同工况；修正 DC/参考限带仍未恢复原头 |
| 包损坏、饱和或输出冻结 | 属于采集失真，而非故障真的没有发生 | 本轮有部分端点堆积证据，但多数错窗无明确基础质量问题 |
| 负载区、滑移、速度变化使调制强弱变化 | 事件重复但幅值与规律不是完全一致 | 需速度、负载和轴承信息；当前不能单凭峰值推断 |

权威实例明确区分了“缺陷重复频率”和“高频冲击响应/包络”：低频原谱未必能区分健康与故障，包络谱可能更清晰。因此“一秒包含很多次冲击”不推出“任意测点、任意带宽和任意分类器都应接近 100%”。[MathWorks 轴承诊断示例](https://www.mathworks.com/help/predmaint/ug/Rolling-Element-Bearing-Fault-Diagnosis.html)

### 1.1 本次实际检查的结果

检查了全部 **88 个窗口、264 个轴信号、12 份录制**，其中已知四类留出评价为 58 窗、46 对、12 错。

- 所有窗口均为有限数值、4000×3；没有整窗精确重复或全 XYZ 平直。
- 根据上游解析记录，保留窗来自计数完整的 4096 点包，再取 4000 点，没有跨包补接。原 DAT 目前不可取得，不能声称本次重放了全部原始字节。
- 460800 的部分文件有大量不完整包。例如滚动体录制只解析出 **3 个完整包 / 41 个已观察包起点**。这说明完整数据产出率低，但不能直接推出已经保留的三个窗口也缺样；该比值也不等于真实硬件丢包率。
- 误判与 RMS、峰度、crest factor、谱形距离的关系，在控制同一录制后并不一致，尚未找到可合法筛掉所有错误的质量指标。
- 58 窗中，只有两个滚动体窗口触发固定端点复查，两个都判错；**另外十个错误没有这种旗标**。

尤其值得先处理的是 bigNormal：全部 12 个接触窗口都有显著固定端点堆积，任一轴命中观测端点约 ±1.998604 的采样时刻占比中位数为 **19.075%**、最大 **23.35%**。这是量程/转换/数据链失真的强烈复查线索；设备量程、单位未知，不能直接宣布“±2 g 饱和”。此前外部电机 0/2 的失败混杂结构、速度和测量条件，应先核实这一测量问题。

### 1.2 要做质量筛选，但应分“确定无效”“需复查”“有效却困难”

建议保留原数据，另生成质量字段，不直接从磁盘删除。

| 层级 | 可以使用的证据 | 处理方式 |
|---|---|---|
| 确定格式/时序无效 | NaN/Inf、长度错误、已证实包内断点却拼接、已确认传感器输出冻结 | 拒绝送入连续一秒模型，保留拒收原因与采集日志 |
| 测量需要复查 | 厂家量程附近平台、量程未知的固定端点堆积、采样配置不一致、噪声底不足以判定 | 核实配置或重采；当前启发式旗标不自动变成删除规则 |
| 信号有效但辨识困难 | 低置信度、故障峰不明显、模型判错、低/高 RMS、较大峰度 | 继续保留用于训练/测试和困难样本分析；不能凭这些现象宣称标签错误 |

不能把“振动很大”“峰度高”直接当坏数据，因为真实故障本来就可能产生强冲击。也不能用测试真值或 teacher 置信度决定哪些测试窗口留下，然后把过滤后的准确率当全系统准确率。

若引入拒识或质量过滤，至少同时报告

\[
\mathrm{Coverage}=N_{accepted}/N_{all},\quad
\mathrm{Acc}_{accepted}=N_{correct,accepted}/N_{accepted},\quad
\mathrm{CorrectDelivery}=N_{correct,accepted}/N_{all}.
\]

还需逐故障类列拒收率，防止把困难故障全拒收。正确输出比例与保留样本准确率是不同指标；这是选择性分类中明确讨论的风险—覆盖率取舍。[SelectiveNet，ICML 2019](https://proceedings.mlr.press/v97/geifman19a.html)

### 1.3 是否需要补采：需要，但优先增加独立采集，而非只多切窗口

先做两个小阶段，避免先采大量存在同一配置问题的数据。

**阶段 A：采集链路核查。** 正常与滚动体两种状态，固定同一转速、负载、测点，115200/460800 两种串口设置各做三次独立会话，每次 120 秒，共 12 份会话、约 24 分钟净运行时间。选择这两类是为覆盖当前端点问题，并非用分类分数选最容易的故障。交替/随机化串口顺序；记录设备采样率、量程、原始串口字节、包计数与接收日志。另在相同安装下留三段静止数据作为独立噪声/偏置基线。若设备支持量程切换，在匹配工况下检查端点堆积是否随更大量程消失。

120 秒会话不保证 120 个连续一秒样本：当前存在发送等待与包不完整，必须报告真正有效采样秒数和采集覆盖率。不要跨缺口拼出 2 秒或 4 秒“连续波形”；长时评价可以平均多个有效块，但须明确其间有空档。

**阶段 B：诊断可重复性。** 先固定一个转速，每类至少五次独立启动/拆装或跨日期录制，按预先指定会话划分三份训练、一份验证、一份新盲测；然后扩展到三种转速，形成 **4 类×3 转速×5 次＝60 份会话**。这是开发起点，不是足以证明稳定 98%/95% 的统计保证。不同轴承实体若可取得，优先整实体留出；同一轴承重复录制只能评估录制/安装变化。

必须先按会话/实体划分再切窗口。量程、质量规则和模型超参数只用训练/验证会话确定；测试会话的两个模态一起封存，不能用其接触式特征构造训练 teacher 原型。报告 1 秒接触式窗口、固定雷达窗口和录制级三个指标，不把它们混为一项。

若进一步要求统计上的高可靠性，样本量需单独设计：在理想独立 Bernoulli 测试且零错误时，一侧 95% 精确下界为 0.05^(1/n)；其超过 98%/95% 分别需至少 149/59 个独立测试单位。同一轴承相邻窗口不满足简单独立假设，不能把 412 个雷达窗口直接当 412 次独立验证。此数值仅说明八次全对为什么证据不足，不是要求第一批就完成这样的大规模采集。

## 2. 微调是否降低了原能力，是否存在泄漏

### 2.1 相同旧协议下的准确率确实有小幅下降

下表为 v0，原测试集 12279 个 query。与本地 79.31%/99.76% 对应的是**前两行逐折模型**；最终保守 all_known 是另一个版本，不混用。

| 修改后的头 | 原十类 Acc | 十类下降 pp | 合并四类 Acc | 四类下降 pp |
|---|---:|---:|---:|---:|
| 115200 训练 → 460800 留出 | 98.8110% | 0.0570 | 99.0064% | 0.0489 |
| 460800 训练 → 115200 留出 | 98.8354% | 0.0326 | 99.0146% | 0.0407 |
| 最终保守 all_known | 98.8598% | 0.0081 | 99.0472% | 0.0081 |
| 原模型基线 | 98.8680% | — | 99.0553% | — |

它们总体均满足最多下降 0.5 个百分点。最终保守版本也通过逐来源数据集约束，但个别小工况仍超过 0.5 pp，不能称任意工况都不下降。全部原训练 query 的四类准确率从 100% 到 99.9942%。

### 2.2 新核查确认：不能笼统声称“没有数据泄漏”

**公开数据源存在明确交叉：**

1. 对全部 135516 条发布 DCN 输入逐行计算哈希，发现 600 组精确重复、涉及 1504 行。其中 148 组跨 train/val/test，涉及 299 行；**31 个 test query、92 个 val query 与 train query 输入逐字节相同**。这是模型输入层面的不独立，不靠推测。
2. 原协议的健康参考从同 condition 全部正常样本中选择，并未限定训练集。原训练输入含 **25789 次来自 test query 的健康参考引用**，涉及 6690 个不同 test query；还包含自引用。正常身份也参与参考选择，不是完全不接触测试信息。
3. 本轮 1174 个回放 query 虽都来自 train，其 3522 个 query-reference 对仍包含 **715 次验证参考、340 次测试参考**。此前协议 JSON 中的 656/296 是对应唯一参考 ID 数，不能误当引用次数。
4. 原 test 的 257/257 个 condition 在 train 出现；物理轴承实体/原始长录制标识不足，不能验证更严格的实体隔离。
5. 保守第二轮是在看过第一轮旧 test 子来源下降后设计的。候选分数由验证集筛选，但整个研究过程已接触旧 test，它是回归集，不能称全新盲测。

**本地数据检查的结论则不同：** 两个录制留出折的训练/测试文件、窗口 ID、源帧无交集；现有 24 个 NPZ、88 个接触窗、614 个雷达窗及 12280 个导出 IQ 帧未发现精确重复；标准化器独立复算与训练录制统计一致，训练原型只取训练录制。当前未发现这些具体路径把留出窗口或留出标签送入优化。

但本地同类两次录制来自**同一轴承实体**，测试是换一份录制，不是换轴承。故障、安装顺序、测点响应和错误距离门可能相关；已反复查看这些数据并做多个分析，它们属于开发数据。简单谱/幅值基线也能很高，不能把高分自动解释为强泛化。反之，高分本身也不是数据泄漏的证明，应以实际输入与划分证据判断。

完整审计结果见 [数据泄露与评估边界审计](/home/huangyating/anomaly_detection/contact_quality_alignment_audit_20260922/leakage/数据泄露与评估边界审计.md)。实际泄漏分类和问题定义的重要性也见 [Kapoor、Narayanan 的方法学研究](https://arxiv.org/abs/2207.07048)。

### 2.3 这些问题是否推翻“原能力保持”

相同旧样本、相同参考、同一评价函数下比较适配前后，仍能回答“在现有旧协议上是否退化”，所以表中的相对下降有意义。**它不能证明独立新轴承上的绝对准确率约 99%。**

本轮另做只读敏感性：仅移除 31 个与训练 query 精确重复的 test query 后，原四类 Acc 为 99.0529%，保守 v0 为 99.0447%，下降约 0.0082 pp。变化很小，说明这 31 个重复并不能单独解释原高分；健康参考共享、同 condition 及未知实体关系仍在。此结果明确标为“不是清洁协议”。

后续需要同时保留两套评价：旧协议作为历史回归；新协议用于独立泛化。新协议先按实体/完整录制分组、去重并锁定划分，再建立独立健康参考池，禁止测试查询兼任训练参考。

**仅给旧预训练权重重新划分测试集，并不能消除此前已经训练过这些信号的影响。** 要获得干净的公开集实验，需在新协议下重建输入并重训基线，再公平比较适配前后；或者使用确实未进入任何训练的新采集数据。目标条件的正常校准若允许，应另设独立 calibration 集，明确区分零校准与已知正常校准实验。

## 3. 目前是否不需要时序对齐

准确说：**当前稳态整段分类基线可以暂不做精细时序配准；目前没有证据支持删除所有时序对齐研究。** 录制身份匹配与同工况片段匹配仍然需要。

### 3.1 一个可以严格证明的事实

当前特征损失只比较均值：

\[
L=\left\|\frac1n\sum_j z_r^{(j)}-\frac1m\sum_i z_c^{(i)}\right\|^2.
\]

任意打乱 i、j 的顺序，求和不变，损失就不变。KD 和对比也基于袋均值，CE 则给同袋窗口相同标签，同样无法区分段内排列。**所以当前目标在数学上不能辨认“时间顺序是否对齐”。**

本次对两个实际保存模型各做 50 次段内随机排列，重新计算四个损失项，最大变化仅 **8.33×10⁻¹⁶**，属于浮点误差。这是实现核验，不是新的训练结果。[实测排列检查](/home/huangyating/anomaly_detection/contact_quality_alignment_audit_20260922/theory/verification.json)

### 3.2 为什么稳态分类仍可不依赖精细配准

若同一段内故障状态、速度和负载稳定，采样具有代表性，编码后统计量能区分类别，那么两模态都可以用多个窗口估计同一个状态的统计特征，不必逐个冲击配对。这是集合/多实例建模的合理应用。[Deep Sets，NeurIPS 2017](https://papers.nips.cc/paper_files/paper/2017/file/f22e4747da1aa27e363d86d40ff442fe-Paper.pdf)、[Attention-based Deep MIL，ICML 2018](https://proceedings.mlr.press/v80/ilse18a.html)

这两篇论文支持排列不变建模，**不证明当前简单均值一定保留全部故障信息**。本报告另外给出均值方差展开、有限平移边界、分类 margin 的充分条件，明确其中平稳性、相关性、无选择性缺测和语义可比等假设。

傅里叶平移性质也提供部分解释：理想整体时移只改变相位，不改变幅度谱；但有限窗口裁切、采样缺口、速度变化和未知传递函数不满足这种无条件不变性。BearLLM 的带符号 DCT 更不能直接按 FFT 幅度不变处理。[MIT 信号与系统课程](https://ocw.mit.edu/courses/res-6-007-signals-and-systems-spring-2011/resources/lecture-9-fourier-transform-properties/)

### 3.3 什么时候必须补时间信息

- 变速、启停、负载切换：至少把相同状态区间匹配，不能把一个模态的加速段对到另一个的稳态段。
- 单窗口 teacher 监督单窗口 student：需要可靠的窗口时间关系或有约束的软配对。
- 冲击定位、波形重建、同类同速度下辨认具体事件：需要精细时序评价，袋分类不能替代。

Soft-DTW 提供可微的单调序列匹配，但应作用于具有可比意义的轨迹，并限制不合理伸缩、保留采样缺口；它不是消除加速度—位移或外壳传递函数的万能方法。[Soft-DTW，ICML 2017](https://proceedings.mlr.press/v70/cuturi17a.html)

下一轮应对比“整段袋均值”“同工况片段袋均值”“偏移/漂移修正后窗口配对”“有约束的软时序配准”，同时做段内打乱、同类错录制配对的负对照。既看分类，也看动态段的事件匹配和已知注入时钟扰动恢复；不能只看高分类率来评价时间算法。

完整数学条件、反例、文献适用边界与实验设置：[时序对齐的条件与证明](/home/huangyating/anomaly_detection/contact_quality_alignment_audit_20260922/theory/时序对齐的条件与证明.md)。
