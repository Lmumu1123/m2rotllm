# 开发性迭代：已知转速的阶次频带与包络

这是看到首轮接触跨转速结果后才进行的开发实验，不是新的盲测，也不覆盖旧 BearLLM 直接推理和留一转速主结果。所有旧权重、主 `contact_features.npz` 和原始输入保持不变。以下分类器是独立基线，没有认证源数据准确率保留，也没有部署为 BearLLM 的替代头。

## 有效结果

三折都在两个转速上训练、另外一个转速上测试；总计 343 包，每包恰好留出一次。每折先按训练会话加权拟合 StandardScaler。下面是除此之外完全相同的前端与 RBF SVM 对照：

| 表示与轴 | 包 accuracy | 包 macro-F1 | 会话正确数 |
|---|---:|---:|---:|
| 固定 Hz，XYZ，原谱+包络 | 154/343 = 44.90% | 42.25% | 7/12 |
| 使用真实转速的阶次频带，XYZ，原谱+包络 | 258/343 = 75.22% | 56.94% | 8/12 |
| 固定 Hz，XY，原谱+包络 | 158/343 = 46.06% | 43.26% | 7/12 |
| 使用真实转速的阶次频带，XY，原谱+包络 | 248/343 = 72.30% | 54.03% | 8/12 |

同前端对照支持：利用已知转速改变频谱坐标，能够改善这批数据的跨转速分类。但两个阶次 RBF 方案对滚动体均为 **0/49 包正确**；看总体准确率会掩盖这个失败。固定 Hz 和阶次对应的物理频率覆盖会随转速不同，这是被测试的归一化本身的一部分。12 个接触会话仍不足以单独排除安装、批次、截顶等条件混杂。

预先限定的 12 个阶次配置全部报告在 `summary.csv`，没有依据留出集再搜索超参数。其中 XY 原谱+包络、线性分类器为 274/343 = 79.88%，macro-F1 68.63%，9/12 会话正确；滚动体只有 9/49 包正确。它是本轮开发配置之一，不作为已确认的最终最优模型，仍远低于接触式 >98% 的要求。

## 前端怎么计算

输入是完整包中间的一秒 4000 Hz XYZ 信号。原信号和包络信号分别逐包、逐轴去均值并除以 RMS，数据集的均值和方差不参与这一步。XYZ 主设置对三个轴的功率平均，XY 敏感性对所有类别统一只平均前两个轴。

- 原信号：1 秒 Hann 周期图，4000 点 FFT，不做额外零填充，Fourier 栅格 1 Hz；Hann 的实际谱响应宽于一个栅格。
- 包络：四阶 Butterworth 500–1800 Hz 带通，SOS 前后向滤波，Hilbert 取幅值，再去掉每端 400 点。对剩余 0.8 秒去均值、按轴 RMS 归一化后计算 3200 点 Hann 周期图，栅格 1.25 Hz。
- 阶次：每包使用已记录真实转速，转频 `f_rot=rpm/60`。将 0.5–20 阶均分为 128 个频带，频带边界乘以该包转频得到 Hz 边界，对原始 PSD 在每带内积分，然后取 log、减去该包本特征块的 log 均值。
- 原谱和包络各得到 128 维，拼接得到 256 维；它们不是 BearLLM 的 DCN 输入或已学好的 128 维 embedding。

真实转速属于额外已知工况先验。部署时必须知道转速，或者另外验证无需接触传感器的转速估计；本轮没有评价转速估计误差。

阶次聚合不会提高物理分辨率。原信号三个转速下的 Fourier 栅格分别约为 0.06、0.03、0.02 阶，包络分别约为 0.075、0.0375、0.025 阶，Hann 窗和有限记录长度仍会展宽峰。

固定 Hz 对照保持上述所有处理、拼接、RBF SVM 参数和数据折分不变，仅把定义频带时的转速恒设为参考值 2000 rpm，于是 128 个频带固定覆盖 16.6667–666.6667 Hz。实际转速仍用于留一转速分组。独立检查确认 2000 rpm 的阶次特征与固定 Hz 特征逐元素完全相同。

## 合成验证及一次被剔除的实现

第一次实现是在稀疏的 128 个阶次坐标上直接取插值点。额外构造的 5 阶正弦测试发现，高转速下点间隔可能跳过窄峰，未通过核验。该次所有产物已保留在兄弟目录 `order_domain_point_sample_failedcheck`，不能使用其数值作为有效阶次结论。

当前实现改为每个频带内积分，保留整带能量。只是修复物理表示问题，没有改变分类器 C、gamma、轴选取或训练/测试规则。合成的 1000/2000/3000 rpm 五阶正弦，以及 1000 Hz 载波上的五阶调幅包络，全部定位到包含第五阶的频带中心 **4.994140625 阶**。幅值按各轴乘以 0.2、3、10 后，特征最大差约 1.1e-13。所有结果 CSV 的 accuracy、macro-F1 均已从逐包预测独立重算。

因此，应使用 `order_domain/` 中的积分版数据，不能引用已失败点采样版曾出现的较高分数。

## 文件

- `protocol_before_results.json`：12 个阶次配置，36 次训练，参数在运行前固定。
- `summary.csv`、`metrics.csv`：阶次配置全部结果，含分转速结果和完整混淆矩阵。
- `order_features.npz`：`xyz_raw_order`、`xy_raw_order`、`xyz_envelope_order`、`xy_envelope_order`、`xyz_concat_order`、`xy_concat_order`，以及 `order_edges`、标签、rpm、session_id、packet_index。
- `hz_control_protocol_before_results.json`：两个固定 Hz 配置，6 次训练。
- `hz_control_summary.csv`、`hz_control_metrics.csv`、`hz_control_features.npz`：固定 Hz 对照。
- `packet_predictions.csv`、`session_predictions.csv` 及对应 `hz_control_*`：逐包和会话预测。
- `verification.json`、`hz_control_verification.json`、`independent_verification.json`：输入哈希、无交叉会话、特征数值、合成峰值及汇总复算核验。

本目录仅保存特征、协议和预测，没有新部署模型检查点。这里的 42 次有效开发拟合不包含首轮接触诊断的 20 次拟合，也不包含失败点采样实现的 36 次归档拟合。
