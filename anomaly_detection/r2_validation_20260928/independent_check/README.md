# 神经实验独立复核

复核脚本不导入训练脚本中的模型或指标函数，不修改实验结果、输入数据或模型。读取四个标记为完成的目录，独立恢复网络前向、训练标准化参数、接触教师目标及物理读取器。

## 核验结果

- 171 个 student checkpoint 全部重新载入并前向计算，包含冻结历史十分类头、折内接触四分类诊断头及直接雷达 MLP。最大逐窗概率误差为 `3.3378601e-6`，录制平均概率误差为 `5.3644180e-7`，在 CPU/GPU 浮点差异容差内。
- 重算 855 条已有指标，与 `metrics.csv` 一致；另从三个留出转速拼成每个种子的完整 OOF 指标。`pooled_oof_by_seed.csv` 是先合并预测再计算 macro-F1，没有把各折 macro-F1 的平均数误称为整体 macro-F1。
- 所有预测 NPZ 仅包含该折留出转速的行，行号、标签、录制 ID 和接触会话 ID 与原始特征文件一致。`recording_predictions.csv` 同时保存 train 和 test 行，角色明确；测试汇总只取 test 行。
- 每折 8 个接触会话训练、4 个不同接触会话测试；96 个雷达录制训练、48 个测试。不存在训练与测试共享接触会话、录制或窗口。
- 独立重新拟合 12 组训练折参数，验证雷达 StandardScaler、接触 StandardScaler、接触会话均值、类别原型、物理目标标准化器和 Ridge 读取器。保存的参数均与仅使用训练转速的数据所得结果一致。
- 新四类诊断头亦由训练转速的接触数据独立复现。该头明确标记 `accepted_for_source_retention=False`，不能被当作满足“原数据准确率最多下降 0.5 个百分点”的正式替代模型。

## 如何理解“没有泄露”

训练代码在循环前计算所有接触样本的标准化值或 logits，但 scaler 仅在训练折拟合，教师蒸馏目标和 KD 概率仅取训练会话。留出接触特征随后只用于评估表示误差、物理读取误差及明确标注的 oracle 控制。这种预先变换全部数据的写法本身没有把留出目标加入训练。

冻结头是实际权重矩阵参与前向：雷达 encoder 输出 128 维，再输入历史十分类线性头，按正常/内圈/外圈/滚动体合并概率；或者输入该折四类诊断头。源头权重没有加入 student optimizer，保存的权重与来源数组相同。直接 MLP 单独标注，不计为通过接触模型诊断。

## 仍然不能扩大结论的地方

1. `full` 是预先固定的旧训练方法移植：CE＋会话均值 MSE＋0.1 类别正样本对比项＋0.5 温度为 2 的 KD。本次执行正确，不等于该目标已经足够表达丰富故障知识，也不等于算法创新获得验证。
2. 主历史头完整方法在 144 个 OOF 录制上的三种子平均 accuracy 为 28.47%，整体 macro-F1 为 18.79%。新四类诊断头下完整方法 accuracy 为 31.02%，真实会话 MSE 为 33.33%，同类错转速目标为 34.03%。本轮没有显示真实转速接触目标稳定优于同类错转速目标；这不证明模型完全没学到知识，但不能据此声称已经传递丰富故障知识。
3. 物理样本仍是 12 个共享接触会话。多个雷达录制、切窗或随机种子不会增加独立教师会话数。未建立跨轴承个体、跨电机、跨环境或故障严重程度泛化结论。
4. 雷达近饱和提示、选区边缘和峰顶超出宽 ROI 的问题没有因为模型前向可复现而消失。该审计保证实验按记录执行，不能证明原始采集质量合格。
5. 若根据本轮结果继续修改前端或训练，后续结果应标为开发实验；本轮数据已经查看过，不能再称为完全未触碰的最终测试集。
