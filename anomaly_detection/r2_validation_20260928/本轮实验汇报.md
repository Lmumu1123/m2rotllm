# R2 新批次完整验证：结果、问题定位与下一步

本轮使用 2026-09-27 采集的新批次；工作目录沿用 `r2_validation_20260928`，汇总于 2026-09-29。环境为 conda `m2vllm`。原始上传数据与既有模型均未修改。

## 1. 先给结论

**这批数据已经完成接触端推理、雷达特征提取、对齐训练、传统分类对照和独立复核，但还没有通过“接触 >98%、雷达 >95%”的跨条件验收。**

最重要的发现是：同一采集条件内可以得到很高分数，换转速、换距离后明显下降。之前的小样本高分不能当作新条件下的泛化结果。新数据让这个问题变得可检验，也表明当前优先级应是修复采集质量、处理工况变化并验证教师能力，而非继续只调分类头。

| 路径与实验 | Accuracy | 这项结果能说明什么 |
|---|---:|---|
| 原有修改版 Bear 接触分类头直接测新数据 | 30.61%（105/343 包） | 旧适配没有直接泛化到新批次 |
| 冻结 Bear 特征，仅用训练转速拟合新线性头 | 31.49%（108/343 包） | 跨转速只改头仍不足 |
| 接触原始频谱分类，同会话前段训练、后段测试 | 99.16%（118/119 包） | 已见采集条件内可分；不是独立泛化验收 |
| 同类接触频谱分类，整条新转速 DAT 留出 | 41.69%（143/343 包） | 跨转速/会话困难明显 |
| 雷达随机森林，同转速/距离留出第 4 次录制 | 97.22%（35/36 段） | 已见条件内雷达可分；不是接触模型的输出 |
| 雷达随机森林，留出转速 | 37.50%（54/144 段） | 不能靠已见工况高分推断转速泛化 |
| 雷达随机森林，留出距离 | 27.08%（39/144 段） | 当前距离处理和频谱形状还不够稳定 |
| 雷达完整对齐 → 冻结的旧 Bear 分类头，留出转速 | **28.47%**（三种子平均） | 当前统一转换链路尚未成功泛化 |
| 雷达完整对齐 → 新接触诊断头，留出转速 | 31.02%（三种子平均） | 换成折内接触新头也没有解决问题 |

“接触包”是完整包中间 4000 点的一秒输入；“雷达录制”是先预测该录制的各个两秒窗口，再平均四类概率得到整段判断。两种统计单位不能互换。所有随机种子的结果都报告，没有挑最佳种子。

本轮诊断链路跑到分类输出，使用 BearLLM 的 FCN 特征和分类接口；**没有重新运行语言模型的自然语言报告生成**，也没有新增 RotLLM/UniFault 的新批次训练。现阶段先验证作为教师的接触表征和雷达传递是否成立。

另有 119 段触发“ADC 数值接近极限”、95 段峰在搜索区边缘、6 段负频率镜像较强。这些是复核提示，**不是已经证明模拟饱和，也不是删除规则**。

343 个完整候选包与 2720 个不完整候选包的比例约为 11.20%；这不是“88.8% 的所有采样点丢失”。断包可能仍含很多有效点，只是不能按当前严格规则拼成完整包。详见[数据审计](/home/huangyating/anomaly_detection/r2_validation_20260928/audit/README.md)。

## 3. 本轮如何避免把高分做出来

主实验采用三折“留一转速”：

1. 用 2000/3000 转速训练，1000 转速测试。
2. 用 1000/3000 转速训练，2000 转速测试。
3. 用 1000/2000 转速训练，3000 转速测试。

每折同时留出对应转速的**全部雷达和全部四条接触 DAT**。训练和测试的 `contact_id` 无交集。StandardScaler、接触均值目标、物理读取器以及诊断新头都只用训练转速拟合。

架构、400 个训练步骤、损失权重、三个种子 `[17,42,73]` 在新批次分类结果出来前写入[实验协议](/home/huangyating/anomaly_detection/r2_validation_20260928/protocol_before_results.json)。采用固定最后一步模型，没有看测试准确率来早停或挑超参数。

这仍是“本批次内跨转速”的验证。每类可能仍只有同一个故障轴承和同次安装；不能把它叫作新轴承、新电机验证。独立教师目标只有 12 个会话，不是 144 个，也不会因为重复三个随机种子变成 36 个物理会话。

同会话留后、同条件留出 rep4、留距离及阶次迭代另行报告。它们的目的和独立程度不同，不能与主实验混在一起取最高成绩。

## 4. 实际采用的完整链路

### 接触端

`DAT完整包 → 中间4000点XYZ → 去均值 → DCT-II与旧DCN规范 → 冻结Bear FCN → 128维表示 → 分类头`

主路径沿用历史 v0 接口、已有公共正常参考和 XYZ 聚合，128 维是分类头真正读取的特征，不是新训练的 PCA。原生十类输出按正常、内圈、外圈、滚动体合并为四类；旧修改版头保持原有权重。

另外测试了官方 final 模型、此前无去均值变体和统一 XY 对照，它们没有解决新批次低准确率，不能据此选一个相对高分就宣称达标。

### 雷达端

`R2复数距离ROI → 50帧/2秒 → 各帧内复数处理 → 128维谱形状 → 训练折标准化 → 雷达encoder → Bear特征空间 → 冻结分类头`

R2 按 5000 Hz 帧内率、192 chirp/帧、40 ms 帧周期处理。没有跨帧直接拼连续波形、相位相减或插值填缺口。

主雷达特征：每个空间单元在本窗口内做幅度尺度归一化；各帧内去复数均值、Hann 窗、1024 点 FFT；平均帧谱、稳健聚合空间单元；在 5–2000 Hz 的固定 128 个频带取能量，取对数并减去本窗口频带均值。标准化参数只从训练录制拟合。

还预先定义了帧内相位增量频谱、按标记距离固定选区的敏感性分支。它们也训练验证了，没有选表现最好者冒充主方法。1024 点 FFT 的网格变细不等于真实分辨率提高；192 点约 38.4 ms 的帧内观测，频率细度约 26 Hz，两秒平均不等于获得了 0.5 Hz 的连续谱分辨率。

雷达 encoder 为 `128 → 128(LayerNorm/GELU/Dropout) → 64 → 128`，最后按训练接触表示的均值、尺度映射并 ReLU，以进入接触分类头的特征空间。

### 对齐从哪里发生

接触端每个故障/转速会话求一个教师表示均值；雷达端将属于该会话的训练窗口表示求均值，学习接近这个教师目标。**对齐发生在 128 维特征空间，监督单位是会话集合，不是逐时刻波形。**

本轮没有可靠的逐窗口同步标签，因此没有伪造一秒接触和两秒雷达的精确配对。链路能够运行不等于已证明“不需要时间对齐”；新数据的泛化失败也不能单独归因于没有做时间对齐。

## 5. 六种对齐训练对照的结果

下面均为主复数谱输入、旧冻结 Bear 分类头、留出转速，先每种子拼接三折测试预测，再对三个种子求平均：

| 训练方法 | 在学什么 | 录制 Accuracy | Macro-F1 |
|---|---|---:|---:|
| Head CE | 雷达通过冻结头答对训练类别 | 26.85% | 26.27% |
| 真实接触会话 MSE | 雷达会话均值接近真实接触会话均值 | 25.23% | 10.47% |
| 完整方法 | 类别＋均值匹配＋对比＋教师概率 | **28.47%** | **18.79%** |
| 类别原型 MSE | 同类两个训练转速共用一个接触均值 | 25.00% | 10.00% |
| 人为类别向量 MSE | 匹配四个让冻结头识别类别的构造向量 | 27.55% | 23.84% |
| 同类错转速 MSE | 故障类不变，但交换两个训练转速的教师目标 | 28.24% | 17.77% |

完整损失为：

`L = CE + MSE + 0.1 × 同类对比损失 + 0.5 × 温度2的KD`

这里旧教师自己对新接触数据的分类就不可靠，真实特征监督与正确类别监督可能互相冲突。完整方法分数不高，也没有显示真实转速目标相较同类错转速目标具有明确优势。

只用训练转速接触数据拟合新四类线性头后，真实均值对齐的雷达录制准确率为 33.33%，完整方法 31.02%，同类错转速 34.03%。这项诊断仍没有解决问题，而且这个新头没有原公开数据精度保持验收，不能替代旧部署头。

### 是否学到了超出类别的信息

把“已经知道真实类别，就直接预测训练集该类的平均接触表示”作为一个强参照，标准化表示误差为 6.114；完整对齐的误差为 6.467。这个参照使用真实测试类别，只是评估用的比较对象，不是可部署的雷达方法。当前完整方法没有超过它，尚不支持“已恢复丰富接触知识”。

物理读取器只用训练接触表示学习六个指标，再读取测试接触/雷达表示；没有用测试物理指标训练。六项全部报告，不事后只挑好的：

| 物理量，误差越小越好 | 直接读取测试接触 | 雷达完整方法 | 知道类别的训练均值参照 |
|---|---:|---:|---:|
| 频带RMS的对数 | 2.161 | 2.494 | 1.864 |
| 峰值因子的对数 | 1.226 | 1.356 | 1.091 |
| 峭度的对数 | 1.128 | 1.098 | 1.109 |
| 20–200 Hz能量比例 | 1.935 | 1.945 | 1.773 |
| 200–400 Hz能量比例 | 1.440 | 1.556 | 1.666 |
| 400–800 Hz能量比例 | 0.543 | 1.335 | 1.209 |

误差以每折训练目标的标准差归一化，按 12 个测试接触会话汇总；重复雷达录制没有增加独立物理目标数。200–400 Hz 比例存在描述性的正面迹象，但 400–800 Hz 中接触表示原本可读出的信息没有被雷达同样恢复。整体还不足以支持丰富知识或严重程度的结论。归一化表示也可能丢掉绝对幅度，不能要求所有幅度指标都必然可读。

## 6. 传统分类基线说明了什么

同一主复数谱输入下，留出转速的录制级结果：线性 SVM 33.33%、RBF SVM 27.08%、kNN 26.39%、随机森林 37.50%；独立训练雷达 MLP 为 29.17%（三种子平均）。

只用幅度/距离相关统计的 RBF 为 50.69%，只用时长、选峰偏移、ADC 极限比例等五个质量统计为 43.06%。它们提示分类与工况、幅度、采集状态有关，但不能仅据此断言标签泄露；幅度本身也可能包含真实故障信息。

![三种验证协议下的雷达传统基线](/home/huangyating/anomaly_detection/r2_validation_20260928/baselines/protocol_comparison.png)

纯雷达同条件重复留出能到约 97%，而跨距离/转速只有约 27%–38%。应把后两者作为下一阶段重点，不再用同条件高分替代泛化目标。

## 7. 已实际做过的一轮物理前端改进

看到主结果后，增加了明确标注的开发性实验：使用已知转速，把频率换为“每转多少次”的阶次，同时提取原信号和固定 500–1800 Hz 带通后的包络。

例如 1000 rpm 的一阶约 16.67 Hz，3000 rpm 的一阶为 50 Hz；把它们都记成一阶，有助于比较随转速移动的重复结构。转速由采集设定提供，不是从测试标签猜测，也不代表无转速输入时同样有效。

最终实现使用 0.5–20 阶的 **128 个频带积分能量**，避免只在离散点插值漏掉窄峰。五阶合成信号和调幅包络在三个转速下都定位到同一个阶次频带，幅值缩放检查通过。早期点采样版本没有通过合成检查，已经归档；其 81.34% 不作为有效结果引用。

为区分不同变化的作用，又加入了同一个周期图、包络、积分方法和分类器，仅坐标固定在 2000 rpm 参考频率范围的 Hz 对照：

| 同一前端及RBF分类器，留出转速 | 包 Accuracy | Macro-F1 | 接触会话正确数 |
|---|---:|---:|---:|
| XYZ，固定Hz坐标 | 44.90% | 42.25% | 7/12 |
| XYZ，阶次坐标 | **75.22%** | **56.94%** | 8/12 |
| XY，固定Hz坐标 | 46.06% | 43.26% | 7/12 |
| XY，阶次坐标 | 72.30% | 54.03% | 8/12 |

这说明转速归一化方向值得继续，但两个阶次 RBF 方案都没有正确识别 49 个滚动体包，不能以整体准确率提高宣称四类诊断解决。另一个预设 XY＋阶次＋线性分类配置为 79.88%、Macro-F1 68.63%，滚动体也只有 9/49 正确。没有把最高数字替换主实验结果。

这些是物理特征＋分类器的诊断改进，**不是已经成功更新 BearLLM，也不是已经完成阶次表征到雷达的蒸馏**。

## 8. 原模型是否受影响，是否有泄露

- 原 FCN、BN 状态、原始/保留头 checkpoint 均保持冻结，源哈希复核通过。本轮没有覆盖它们。
- 新四分类头单独保存，明确 `accepted_for_source_retention=False`。没有执行新头的全公开数据回归，因此不能说新头满足“原准确率最多下降0.5个百分点”。
- 在本轮主协议中，没有发现测试转速、测试 DAT 或测试雷达用于拟合的路径；全数据提前做不学习参数的特征提取不等于在全数据拟合 scaler。
- 同会话前后段诊断明确共享 DAT；同条件 rep4 仍可能共享安装、轴承和采集会话。这些较弱协议不冒充独立泛化。
- 独立程序重新载入 **171 个神经模型**，前向核对并重算 **855 条指标**。最大逐窗概率误差约 `3.34e-6`；scaler、教师目标及物理读取器也独立重建一致。详见[独立复核](/home/huangyating/anomaly_detection/r2_validation_20260928/independent_check/README.md)。

## 9. 下一步的优先顺序

**第一步，先补小规模硬件质量验收，而不是立刻再做144组。** 调大接触量程试录（例如先检查设备支持的8g档位），直到内圈高转速下不再出现端点平顶，并检查噪声分辨率。量程不能仅凭已经截顶的幅值反推。检查串口采集程序、缓冲及设备发送格式，统计每条录制的完整包/连续有效样本；不要通过插值掩盖断包。

**第二步，纠正雷达的几何依据。** 确认距离从天线面量到哪个被照射表面，复核朝向。对现有20cm原始BIN补导更宽复数距离范围，再评估相位/空间单元质量；不能只靠功率图补回相位。已准备[48条20cm补导清单与命令](/home/huangyating/anomaly_detection/r2_validation_20260928/local_reexport_20cm/README.md)。该补导需要Mac原始BIN，本轮尚未执行。

**第三步，先让接触教师在跨转速条件下可靠。** 保留绝对频率和阶次/包络两条分支，重点处理滚动体。若需要改Bear骨干或adapter，用旧公开数据回放/蒸馏约束，再按既定0.5个百分点规则做独立回归；仅冻结旧权重不等于新诊断头已经通过这条规则。

**第四步，再更新跨模态目标。** 教师稳定后，考虑把故障类别信息与转速相关信息分别约束，比较同类真实工况目标、同类错工况目标和类别均值；雷达前端可继续检验带缺口的长时统计、包络阶次和空间单元可靠性加权。当前帧内谱较粗，不能直接宣称已保留细故障谐波；这些新前端尚未实现验证。

**第五步，固定方案后重新采独立留出批次。** 本批已用于诊断与阶次开发，不再作为以后反复调算法后的最终盲测集。至少把新的完整采集会话留出；同一条DAT内继续切片不能替代它。仍可不以跨电机结构泛化为主线，先把跨转速、跨距离和接触知识传递证据做好。
