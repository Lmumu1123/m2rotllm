# R2 雷达帧内特征导出

本目录读取已上传的复数距离 FFT 数据，生成后续分类和跨模态训练需要的确定性输入。没有训练模型，没有拟合全数据标准化器，也没有根据类别改变选区或删除窗口。主表示和对照表示在看分类结果前固定。

## 输出

- `features.npz`：主表示 `complex_shape`、副表示 `phase_shape`，均为 `[窗口,128]`；`geometry_complex_shape`、`geometry_phase_shape` 为固定物理位置选区敏感性实验；`nuisance` 是 12 维幅度、位置诊断输入。
- `metadata.csv`：每行与上述数组一一对应，包含录制 ID、共享接触会话 ID、类别、转速、距离、重复编号、起始帧和质量标记。
- `recording_quality.csv`：每条录制质量汇总。
- `recording_spectra.npz`：供画图检查的录制中位谱，不能将谱线密度理解为独立测量的数量。
- `feature_schema.json`：精确参数、表示语义和方法边界；`input_manifest.json` 保存来源。

## 主表示如何计算

1. 一个两秒窗口取连续 50 帧；每帧 192 chirp，每个 chirp 相隔 0.2 ms。50 帧有 9600 个实际观测，帧间名义缺测比例 4%。**不把缺口删除后当作连续 5 kHz 波形。**
2. 输入来自 4 个 RX × 5 个距离单元的复数信号。这是 20 个相关空间单元，不是 20 根独立天线。
3. 在每个窗口里，以每个空间单元的原始幅度中位数做除法，减少幅度尺度的支配。随后每帧单独减慢时间复数均值、乘 Hann 窗、计算 1024 点 FFT。
4. 合并正、负频率的功率，先对完整帧求平均，再对空间单元取中位数。这样对于复数共轭，慢时间功率表示保持一致；**这不意味着错误的原始 IQ 排列或错误的距离选区被修复**。
5. 在 5–2000 Hz 之间固定分成 128 个等宽频带，对线性插值的 PSD 积分并除带宽，得到各带平均能量。取 log10 后减去该窗口 128 个数的均值。

没有使用训练集之外拟合的均值、方差、PCA 或标签。后续 `StandardScaler` 必须只在当前训练折拟合。

**频率分辨率限制：**每帧只含 38.4 ms 观测；未加窗的 Rayleigh 频率间隔约 26.04 Hz，Hann 主瓣还会更宽。FFT 的 4.88 Hz 评估间隔及 128 个频带都是密集表示，不能恢复低于原始观测长度限制的细频率结构。两秒主要增加平均帧数、降低估计方差，并没有在这条帧内方法中直接提供 0.5 Hz 分辨率。因此后续如果发现转速或故障特征读取较差，需要比较经过验证的带缺口长窗口方法，不能只增加 FFT 点数。

## 副表示和选区敏感性

`phase_shape` 首先计算同一帧相邻 chirp 的 `angle(z[t] * conj(z[t-1]))`，之后做与上面类似的帧内功率估计。它是相位增量谱，不是未经校准即可换算为毫米的位移谱；没有跨帧展开相位，也没有跨缺口相减。低幅度、接近 π 的增量比例另行记录。

主表示沿用上传时的紧凑 ROI。考虑到一批录制的最强变化能量位于搜索区边缘，本次预先规定另一个分支：从宽 ROI 中，围绕声明的 20/40/80 cm 选择最近的连续五个距离单元；不按故障标签或分类成绩选位置。两分支都报告，不能事后用测试集更好的分支覆盖主结果。这项实验只说明选区敏感性，声明距离本身也不能保证恰好对应同一个壳体散射点。

并行距离轮廓审计发现，较多主反射峰比声明距离多约 8–14 cm，20 cm 的多个峰顶已在保存的宽 ROI 之外。因此这里的固定距离分支不是对真实峰顶的修复，现有宽 ROI 也不能恢复范围外的复数数据；后续诊断必须保留这项限制。

`nuisance` 包含原始功率的均值、中位数、10%/90% 分位数、帧内变化功率均值/中位数、四个 RX 的平均原始功率、选区平均位置和声明距离。它是诊断性对照；幅度也可能含真实故障信息，不能把它的高分直接等同于采集作弊。

## 质量与划分约束

不因分类结果或标签删除数据。一个窗口如果有无效或非有限帧，只使用该窗口内完整帧估计 PSD，并记录比例；若整个窗口不可估计，输出零向量并显式标记。全部完整两秒窗口都保留。每条末尾不足两秒的帧仍留在原 HDF5，本特征文件不把它补成完整两秒。

接触 ID 表示共享长会话，不表示一秒接触包与两秒雷达窗口同步。12 个接触会话不能因为关联 144 个雷达文件而当作 144 个独立教师样本。repeat 是按各条件文件时间排序的编号，不能自动视为跨距离统一的独立批次。

本次 128 维的频带定义为 5–2000 Hz，与历史 5–800 Hz 的 128 维表示不同。**维数相同不意味着可以直接使用历史雷达 encoder 的 scaler 和权重。**新实验应训练该表示对应的雷达 encoder，接触端模型与接触表示接口另行核验。
