# 下一轮算法与补采实验方案

制定依据是本轮[实际结果](全链条实测报告.md)，不是假定原教师或跨电机泛化已经成功。下面全部是**尚待执行的实验**。按用户的 11 月 5 日内部目标安排，优先拿到可解释的新证据；增加模型复杂度必须有独立验证支持。

## 1. 先解决三个已经观察到的问题

## 2. 最小但有解释力的物理实验矩阵

### 2.1 14 天核心：48 对同步录制

先固定一个工作转速和负载、接触测点/轴向、已验收雷达 cfg 和增益。转速选台架能稳定重复的值，不从故障分类结果反推。

| 因素 | 水平 | 要求 |
|---|---|---|
| 状态 | 正常、内圈、外圈、滚动体，4 类 | 类别覆盖完全相同的采集条件 |
| 环境 | room、narrow，2 类 | 尽可能同一台架和传感器安装；若搬动必需，记录安装变化，不能说只改变多径 |
| 距离 | 40 cm、80 cm，2 类 | 实测到目标表面，记录方位/仰角，所有类别一致 |
| 独立重复 | 每条件 3 次 | 各次重新启动；至少一次重新定位雷达，并记录变化；相邻文件切片不算独立重复 |
| 单次时长 | 60–90 s 稳态 | 包含 ≥20 个合格接触包为初始质量目标；达不到应延长或修接收 |

总计 `4×2×2×3=48` 对，净运行采集约 48–72 分钟；安装、启停、转速稳定和校准另计，实际应安排数天。每个环境/距离另采不进入分类测试的 off；设备静止时保持支架、朝向和场景一致。

另备独立健康 reference：可按每个环境/距离至少 2 次单独录制准备。**有目标环境健康参考是一种额外已知健康校准信息。** 必须分别报告：严格源环境参考的跨环境测试；允许目标健康校准的测试。后者不能叫无需目标数据的泛化，所有对照必须获得同等校准信息。off 也属于目标域无标签校准，应单列条件。

如果同一台架不能进入两处环境，可在固定台架附近进行可复现环境干预，例如移动普通金属反射物、改变背景布置。此时如实称“受控环境干预”，不能将不同系统/电机之间的差异全部解释成 room/narrow。不需要增加同步硬件。

同类若目前只有一个轴承实体，这 48 对只能支持录制、环境和位置泛化。独立轴承实体留出需要每类多个物理轴承；不能把同一轴承的重装当另一个实体。推荐至少 3 个实体/类才能安排实体级训练、验证、测试；若资源不够，明确缩小主张。

### 2.2 扩展转速：先加 24 对，避免立即做全因子

核心矩阵稳定后，在固定开发环境/距离加两个额外稳定转速，各类各 3 次，新增 `4×2×3=24` 对。它可以构成留一转速测试，但不能支持完整“环境×距离×转速组合泛化”。若核心转速与新转速的采集日期不同，要交错插入核心转速的正常/故障复测，排除温升或日期与转速绑定。

完整交叉规模为 `4类×2环境×2距离×3转速×3重复=144` 对；只有采集质量和第一阶段效益明确时再扩展。长期数据增加以独立实体和困难条件为主，避免只增加同一录制的窗口数。

### 2.3 外部电机：最小 12 段病例检查

现有另一系统的好、坏电机各自做 `2个匹配或明确记录的转速×3次独立启停=6` 次，共 12 次；尽可能同距离、同朝向、同增益与负载。若坏电机没有已知故障部位，只评价正常/异常与已知类分数，不给它伪造内圈/外圈/滚动体标签。

先在源域冻结模型和拒识阈值，再采集这批数据。bigNormal 当前两文件已被看过，并触发了事后方法检查，应归入开发病例，不能继续当新的封存泛化测试。

## 3. 采集记录与划分方式

每份文件保存：`recording_uuid, session_id, bearing_entity_id, motor_id, fault_type, environment_id, measured_distance_cm, azimuth, elevation, commanded_rpm, measured_or_controller_rpm, load, contact_location, xyz_orientation, range_and_units, fs_contact, radar_cfg_sha256, rx_gain, start/stop_receive_times, packet_counts, frame_counts, dropped_packets, reference_id`。

转速来自控制器设定/反馈时分别保存，不能默认设定值等于真实转速。缺少转速计并不妨碍记录已有控制器信息，但由谱峰推断的候选值必须另列且带置信度。文件名保留可读状态可用于人工管理，网络输入必须显式排除名称和状态字段。

预先建立一个源域开发划分和至少一个封存测试环境：

1. 每个原始录制及其全部模态、轴、距离单元、重叠窗必须同组。
2. 若声称实体泛化，分组键优先为 bearing_entity_id；同实体所有条件整体划分。若只有一个实体/类，只能以 session 分组并注明限制。
3. 验证集仅来自源域独立 session/实体。频带、ROI规则、损失权重、轮数、阈值均在这里确定。
4. 未见环境测试：源环境训练/验证，另一环境所有录制只测试；如要双向协议，应在看任何目标成绩前冻结两个方向的全部超参数和报告方式。
5. 未见距离与未见转速分别单因素留出；组合留出需要完整交叉数据，否则不能将多个改变拆开归因。
6. 主分数按独立录制或实体汇聚概率计分，macro-F1、balanced accuracy、每类召回及正常误报率并列。置信区间按真实独立 session/实体分组 bootstrap；样本太少就给原始计数和每个病例，不用窗口 bootstrap 制造窄区间。

## 4. 无新增同步设备：下一版时序对应算法

### 4.1 先承认可辨识性限制

单一转速的长稳态周期信号可能出现多个同样好的时延解，且点加速度和面位移经过不同机械/电磁路径。没有可靠时钟或可识别变化时，不能保证从两条信号唯一恢复时间对应。起止加减速能提供实验锚点，但不应成为日常部署必须有的动作；训练有双模态时做校准，部署仅雷达时不再要求接触设备。

接收时间是采样时间的带延迟观测。接触每包若有设备样本计数，优先保留；若没有，则保存接收首字节、末字节的单调时钟时间和包内序号。不要直接把接收时刻当首采样时刻，也不要用包编号乘 1.024 s 跨越未知间隙。雷达使用实际帧/chirp 时刻和丢包 mask。

### 4.2 分三层实现，每层都能拒绝低可信对应

**第一层：粗时钟映射。** 用 `t_r=a·t_c+b` 表示相对时钟漂移与偏移。接收时段给 b 的候选区间；a 的搜索范围依据设备说明或开发数据计量设定，不能凭空认定某个 ppm。包内采样按确认的 4000 Hz 展开，包间缺口保留缺测。

**第二层：匹配对传递幅相较稳健的变化轨迹。** 两模态各用共同有效频带内的多带 log 能量变化、峰群移动、包络变化和变化点置信度；按各自源域统计归一化。先匹配“何时发生变化”，不直接最小化原波形点差，也不对毫米波相位做二次微分来强行生成同测点加速度。候选事件用稳健回归估计 a、b，并保留多解和匹配残差。

**第三层：受约束软对应。** 在粗映射附近建立窗口代价矩阵：

\[
C_{ij}=\alpha\,d_{feature}(u_i,v_j)+\beta\,\rho(t_j-a t_i-b)+\gamma\,d_{change}(u_i,v_j).
\]

使用带未匹配质量的单调路径或非平衡软匹配；每个接触窗口允许对应多个雷达窗口或不对应，缺失窗口不能被迫匹配。约束顺序单调、局部时间偏差范围和斜率变化，避免自由 DTW 把不同故障事件任意拉伸。时间代价与特征代价的量纲需用源验证集固定尺度。

得到 `P_ij` 后，用 `sum_j P_ij z_cj / sum_j P_ij` 形成雷达窗口教师目标，仅当对应质量超过验证阈值时使用；低可信窗口退回 bag 监督或拒绝对应。学习初期用固定物理轨迹求 P，训练若干步后才允许由冻结/stop-gradient 的表示更新 P，防止 encoder 与匹配互相配合产生退化解。

当前模型仍保留 bag 基线；高级匹配不必然更好。只在新数据中能证明改善对应质量或最终诊断时，才把它作为论文组件。

### 4.3 对齐如何真正验证

| 测试 | 实施方式 | 能证明什么 |
|---|---|---|
| 代码与参数恢复 | 在有已知公共时间轴的开发数据上注入预设偏移、线性漂移、突发丢包；范围由实测日志决定 | 对人为扰动的恢复误差；不能替代真实传感器同步证据 |
| 人为变化序列 | 少量专门记录开始/中间/末尾的不同增减速序列，保存控制命令时刻 | 提供物理事件区间；命令时刻不等于机械响应时刻 |
| 真实对应复核 | 预留不参与估计的变化事件，报告时间区间残差及覆盖率 | 检查是否泛化到未用事件，仍需报告锚点本身误差 |
| 稳态与多解 | 固定转速长稳态、周期重复变化 | 算法是否输出低置信或多解，而非虚报精确偏移 |
| 同类错配 | 同类同转速的不同录制互换教师 | 区分实例对应增益与单纯类别原型蒸馏 |
| 参数化基线 | 接收时间、全局互相关、单一仿射映射、受约束 DTW、bag 蒸馏 | 判断复杂对应算法是否必要 |

指标同时包括：可信匹配覆盖率、可信部分的时延/漂移误差或锚点区间残差、错配率、对齐后诊断 macro-F1、计算开销。不能只展示一张对齐波形图。精确时间真值不可得的真实样本，不报毫秒级“真值误差”。

## 5. 环境与结构鲁棒性：先建立可证伪假设

### 5.1 环境前端候选与对照

从原始 IQ 保留统一 ROI 的全部候选 RX/bin，结合几何、ADC质量、off 动态噪声与稳定性选择或加权，不使用故障真值选门。比较：固定几何门；ROI 内最大动态能量；多单元中位谱；质量加权多单元谱。错误几何、近满量程或低有效样本情况进入覆盖率统计。

off 校准比较无校准、功率噪声底扣除/收缩、开发源 off 校准、允许目标 off 校准。跨时间相位未保证时，不能直接用一段 off 的复数均值相减声称消除了另一段的静态多径。扣除功率后设置非负约束并记录被截断频带，避免只保留最有利结果。

同一正常/故障条件，在固定 cfg 下做增益、距离、角度、反射物单因素干预；同时记录接触信号稳定性，用于区分实际振动变化与雷达路径变化。饱和前端需降低增益重采，归一化无法修复已失真 ADC。

### 5.2 结构影响不能用一次全局 PCA 消除

理想化频域写作 `a(f)=H_c(f)s(f)+n_c`，`r(f)=H_r(f;geometry,structure)s(f)+n_r`。两个 H 随测点、轴向、壳体和散射发生变化，甚至会有频带零点。因此不存在无条件保留全部故障信息且完全不受结构影响的固定特征。

可检验候选是多视角表示：标准化谱形状、经可信转频校正的谱群/调制特征、包络统计、相位速率谱，以及各自的质量和有效频带。转频不可信时保留缺测标志与原频率分支，不硬做 order normalization；本轮简单主周期归一化已经失败。

按用户给出的 PHI-S 定义，PCA 后用归一化 Hadamard 矩阵混合可让坐标方差更均匀，但一般不会使完整协方差成为单位阵，也不会消除结构域变量。若加入，只能在训练来源估计均值/PCA/全局尺度；与 StandardScaler、PCA、白化、随机正交旋转分别比较。使用低维投影时应单独对齐维数，不能把降维收益归因于 Hadamard。

结构域的“故障信息/条件信息分离”只有在每种故障都跨多个条件出现时才可检验。当前类别与选门绑定，直接训练域对抗网络可能同时删掉故障信息；修正采集平衡后再考虑环境对抗或条件化 adapter。即使跨环境成功，也不能自动声称跨任意电机结构成功。

### 5.3 教师带宽、参考与置信度

新增接触教师消融：现有 0–2 kHz 表示；仅共同 5–800 Hz 支持；简单接触频谱；独立同工况正常参考；固定外部参考；零参考。对频带的修改同时作用于 query/reference，且每种方案只在源域重新拟合头。

高频接触表示可以作为训练时特权信息，但不能据此声称学生重建了雷达不可观测的高频波形。若教师在某源条件本身低可靠，蒸馏应减权或屏蔽该条件；质量/置信权重与阈值在独立源验证集校准，不按目标真值决定哪些教师被保留。

## 6. 让知识迁移产生可评价收益的实验

| 问题 | 固定比较 | 主要指标与公平性要求 |
|---|---|---|
| 表示是否值得复用 | 接触预训练 vs 同结构随机初始化；线性频谱/统计 | 使用同样训练录制、分类头、预算和选择规则 |
| 蒸馏是否减少雷达标注 | 每类 1/2/4 个独立训练录制预算，雷达监督 vs 接触教师迁移 | 不能用每类 1/2/4 个相邻窗口冒充独立录制预算 |
| 没有额外雷达人工标签 | 仅同录制接触教师标签/软概率；删除雷达真值 CE 与真值定义的正例 | 表述为“无额外雷达人工标签”；接触标签及同步对应仍是监督资源 |
| 同步是否有独立价值 | 同 bag、同类不同 bag、跨类错误 bag、可信窗口对应 | 同类错配比当前跨类错配更能区分实例与类别信息 |
| 环境/距离迁移 | 完整条件留出；目标健康/off 校准各单列 | 目标数据权限保持一致，严禁源方法无校准却让主方法有目标标签 |
| 损失必要性 | CE、CE+feature、CE+KD、CE+contrast、full；固定头和独立头 | 每项单独加入及移除，预算一致，报告验证选择成本 |
| 时频/相位必要性 | 帧谱、相位谱、组合、IQ时序小网络 | 相同有效带宽、参数量近似匹配，公开缺口处理 |
| 未知故障 | keep 留出，源内独立校准阈值；已知错误率约束下的拒识覆盖 | 当前 keep 错误 ROI 修复后才进行；另采未知类型可减少对单一未知的过拟合 |
| LLM 的独立作用 | 同一 p4 下固定模板 vs 真 LLM | 类别忠实度、证据外推率、延迟；不能把上游已对的分类算作 LLM 增益 |

优先报告同预算下的文件级差值、每类错误、正常误报、覆盖率和失败条件。所谓“优于”需要多个独立 session/实体/环境支持，不能靠一组对照种子恰好低分。

RAG 可在诊断后检索设备手册、故障定义和已确认测量证据，输出可追踪来源；它不应检索目标真值，也不能纠正未被观测到的频带。SFN 若指特定论文算法，需明确全称和公式后再做独立消融，本轮没有凭缩写编造实现。二者当前优先级低于有效信号、教师质量和泛化验证。

## 7. 可执行的 14 天安排

| 时间 | 工作 | 完成标志 |
|---|---|---|
| 第 1–2 天 | 原 bin 统一 ROI 重导出；采集日志/完整包检查；核对 cfg 与实际转速 | 新距离门质量报告、全输入哈希、可复现丢包统计；异常不过关不进入正式采集 |
| 第 3 天 | 另采独立正常 reference；用少量开发数据验证原教师/适配教师 | 教师 source-validation 结果及固定参考列表；冻结基本前端 |
| 第 4–7 天 | 完成 48 对核心录制与 off；交错类别顺序，记录实体和 session | 每个条件所有类别齐全；低质量条件重采并保留失败日志 |
| 第 8 天 | 检查几何、包质量、采样时间；生成实体/session/环境划分清单 | 不看测试性能确定 QC/划分；封存测试清单和文件哈希 |
| 第 9–10 天 | 源域验证：线性强基线、普通 MLP、冻结头、bag 蒸馏；可选可靠窗口对应 | 参数、种子、轮数、阈值与可访问校准信息写入协议 |
| 第 11 天 | 一次性运行预定环境/距离测试及全部消融 | 完整结果表，包括错误和简单基线，不按测试重选算法 |
| 第 12 天 | 新外部好/坏电机病例；若采集允许加转速测试 | 独立误报/异常检查；无法匹配工况时明确标注 |
| 第 13 天 | 仅雷达推理、LLM忠实度、系统延迟/内存/采集时长测量 | 从原始数据到有效预测的成本拆解和覆盖率 |
| 第 14 天 | 整合复现包与论文证据表 | 每项主张有实验或明确失败；决定继续主线或收缩范围 |

如果原始 bin 暂时不可用，先做接触参考与接收程序修复，但不要把现有四类雷达分数升格为有效物理结果。如果教师在独立本地参考和源验证后仍明显失败，应先收缩到可诊断频带或正常/异常任务；如果监督基线在新困难测试仍与蒸馏一致，则论文重点需转向有独立证据的系统观测与可靠性，而不是硬称蒸馏创新。

## 8. 面向投稿的继续/收缩判断

到中期至少需要看到：正确 ROI；未见独立录制/实体的可复现诊断；条件平衡的环境测试；强监督基线；迁移或可靠对应的可重复增益；系统成本与质量拒绝覆盖率。当前一台台架与另一系统少数电机，只能支撑有限结构范围，论文标题和主张应与实际覆盖一致。

复杂方法不是当前最稀缺的部分。现在最有价值的新增证据是：同一故障在不同环境/距离仍被识别，同一环境中不同故障确实可分，未知正常电机不会被普遍误报，而且这些效果超出简单幅度或主频分类能够解释的范围。
