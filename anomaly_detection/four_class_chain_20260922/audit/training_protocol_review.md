# 主训练协议独立审阅与修复记录

2026-09-22，审阅 `scripts/run_chain.py` 与根目录 `protocol.json`。本审阅先于主实验结果解释，不运行额外模型来选择方法。

## 泄漏与梯度检查

未发现代码将目标数据用于 scaler、接触式适配头或蒸馏目标拟合。训练读取全量数组后，只对训练 bag 采样反向传播；LayerNorm 不在样本之间累计统计。接触式 frozen FCN 已在独立导出阶段完成，学生训练中的教师中心和线性头均为固定张量，没有梯度更新。学生窗口概率先在每个 bag 内平均，再计算文件级指标；温度 KL 同样比较教师与学生的 bag 平均概率。

四类穷举为 16 个折、三类为 8 个折，各另加一个 `all_known` 外部案例训练。重复 fold 和 seed 不是独立物理实验；全部外部 keep/bigNormal 均从训练和标准化排除。主训练固定 200 步，5 步 smoke 仅检查工程接口，不能作为性能结论。

## 已落实修复

| 审阅发现 | 修复后行为 |
|---|---|
| 原头推理用原 FCN linear2，但保存文件只有适配头参数 | checkpoint 记录 `output_head_type`，原头分支另存 `original_coef`、`original_intercept` 与原权重 SHA256 |
| 原概率平均与平均 hidden 后过原头不等价 | 增加 `contact_original_mean_hidden`，与原逐参考/三轴概率平均基线分开报告 |
| `no_radar_labels` 名称可能被理解成完全无标签 | 改为 `no_radar_CE`；它仅移除雷达直接交叉熵，教师头及类别正例仍来自有标签训练数据 |
| all_known 中滚动一个 bag 后部分错配仍是同类 | 按 `nbag/nclasses` 滚动，确保所有 bag 教师跨类错配 |
| 三类任务将原头 outer 概率去除后重归一化 | 保留原四类完整概率；预测到 outer 计为超出候选集合的错误，不隐去失败 |
| all_known 实际只用 seed42 而协议未说明 | `external_model_seed=42` 显式记录；普通折使用 17、42、73 |

以上修复已由代码只读复查确认。原十类头仍只有同一线性头的数学复用意义，平均隐藏量会改变原始概率聚合过程；新的四类线性头属于本地适配，不是原头零修改复现。几何错误版本四类输出、未知转速/负载和参考条件失配的限制仍然存在。

初次审阅的逐项机器记录及原脚本哈希见 [main_script_review.json](main_script_review.json)；该 JSON 是修复前快照，不应被当成当前问题仍未修复的状态。
