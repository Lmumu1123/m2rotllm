# 一条命令执行雷达独立推理

`predict_chain.py` 串联已保存的雷达 encoder/分类头、真实冻结 BearLLM/Qwen 生成，以及语言一致性和目标距离检查。推理时**不需要接触式数据、故障标签或 state 字段**。默认拒绝非空输出目录，避免覆盖已有结果。

下面的演示输入只含 `frame_shape[614,128]` 及四个元数据列：`bag_id`、`geometry_roi_mismatch`、`range_center_m`、`intended_distance_m`。它已实际完成全部 12 个文件的端到端推理。

```bash
conda run --no-capture-output -n m2vllm python \
  /home/huangyating/anomaly_detection/four_class_chain_20260922/scripts/predict_chain.py \
  --model /home/huangyating/anomaly_detection/four_class_chain_20260922/results/chain_v1/models/four_class_provisional_roi/all_known/distill_seed42.pt \
  --features /home/huangyating/anomaly_detection/four_class_chain_20260922/results/radar_only_demo_inputs/features.npz \
  --metadata /home/huangyating/anomaly_detection/four_class_chain_20260922/results/radar_only_demo_inputs/metadata.csv \
  --output /home/huangyating/anomaly_detection/four_class_chain_20260922/results/radar_only_chain_demo_new \
  --device cuda:0
```

`--features` 是预处理后的雷达特征 NPZ，不是 DCA1000 原始 bin。特征键及维度由保存的 checkpoint 决定，当前模型需要 `frame_shape`。元数据必须与特征逐行对应，最低要求只有 `bag_id`；几何字段缺失或不完整时会标记距离状态未核验，不默认放行。对于新的采集数据，先完成相同 cfg/时间轴/距离 ROI 的预处理，再运行此命令。

已有演示结果在 [radar_only_chain_demo](../results/radar_only_chain_demo/predictions.csv)，重复运行示例使用新目录 `radar_only_chain_demo_new`。

| 输出 | 内容 |
|---|---|
| `predictions.csv` | 四类概率、结构化闭集候选、几何状态、原始 LLM 文本、语言冲突、回退文本、未知检测能力标记 |
| `window_predictions.npz` | 每个雷达窗口的概率与 encoder 表示 |
| `actual_radar_geometry.csv` | 仅由本次输入元数据汇总的每文件几何状态 |
| `llm/generation_predictions.csv` | 真实 Qwen 生成的完整记录 |
| `llm/guarded_predictions.csv` | 一致性规则结果；不修改原生成文本和分类概率 |
| `inference_manifest.json` | 输入/模型/脚本哈希、运行环境、调用链和限制 |
| `verification.json` | 本次演示与已有雷达独立概率的一致性及无标签检查 |

本次演示：614 个窗口、12 个文件；4 个文件因输入实际距离单元异常标为 `invalid_target_roi`，其候选类别不能作为有效诊断；其余仍为实验性闭集候选。12 条语言输出均与分类器 argmax 一致，本次无语言回退。此前主实验的 1 条冲突仍原样保留，不因本演示而被替换。

由于复用现有数据，此演示包含模型训练时见过的录制，**只验证推理接口和依赖完整性，不报告测试准确率或 F1**。兼容已有 LLM 脚本时使用的 `true_label=-1` 是常量占位，不是真值；task/fold/direction/modality 也只是接口字段。最终 `predictions.csv` 不含标签或 state。

结构化诊断以分类器概率与 argmax 为准；若 LLM 生成的类别不一致，仅语言文本回退为标准类别短语。这个一致性由规则保证，不能算成语言模型性能提升。所有输出均明确是已知类别的候选，闭集置信度不能证明 keep 或其他未知故障已被识别。
